title: Drawer
description: "基于 Dialog 支持四边放置、拖动关闭和纵向高度吸附。"
---

<ComponentPreview name="drawer" height={360} />

`DrawerState` 组合了一个 `DialogState`。使用 `new(window, cx)` 构造它，或
通过 `with_dialog` 采用已配置好的 Dialog；并在一个 Drawer 中挂载该状态。
`open`/`close`、初始焦点、焦点限制、Escape、背景遮罩关闭和返回
焦点仍由 Dialog 负责。该状态会转发 `DialogEvent`，并为普通的 DialogClose 控件
暴露 `dialog()`。

Drawer 默认从底部打开。在挂载前给 `DrawerState` 指定 `.side(Placement::Left)` 等方位即可更改所在边缘。
四个方向均可通过 `.handle(...)` 提供的手柄向外拖动，正文仍可正常滚动和编辑。
未配置吸附点时，向边缘拖过面板长度的三分之一即可关闭，拖动较短则恢复原位。

顶部或底部的 Drawer 可通过 `.snap_points([0.5, 0.85])` 以窗口高度的一半打开。
拖动手柄可调整高度，松开时面板停在最近的高度（包括关闭位置）。
请按严格递增顺序传入大于 0 且不超过 1 的比例。窗口大小改变时仍然使用这些比例。
目录中的会话确认示例通过 `snap_index()` 和 `set_snap_index(index, window, cx)` 提供可由键盘操作的高度按钮。
窗口失去焦点会取消当前拖动，再次打开时会保留上次停靠的高度。
