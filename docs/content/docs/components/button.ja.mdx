`Button` は、他のコントロールが土台とする操作のプリミティブです。
ポインターと Enter/Space による操作、フォーカス、無効状態、ネイティブの
Button ロールを担当し、内容、間隔、形状、状態のスタイルはアプリケーションが管理します。

[CLI をインストール](/ja/docs/installation/)した後、アプリのルートで次のコマンドを実行すると、プレビューのライト・ダークのボタンスタイルをコピーできます。

```sh
gpui-deck add button --to src/ui
```

```rust
use ui::{Appearance, recipes::ButtonVariant};

let palette = Appearance::Settings.palette();
ButtonVariant::Primary
    .apply(Button::new("save").accessibility_label("セッションを保存"), palette)
    .on_click(|_, window, cx| {
        // The application decides what activation does.
    })
    .child("保存")
```

## 操作とフォーカス

クリック、Enter、Space のいずれかでボタンが 1 回操作されます。`.disabled(true)` は
操作を無視して Tab ストップを取り除きます。フォーカス中に無効化されたボタンは、フォーカスが離れるまで
フォーカスのバインディングを保つため、Tab はどちらの方向にも続けられます。
`.track_focus(&handle)` はアプリケーションが所有するフォーカスハンドルを使用します。たとえばダイアログが閉じた後に
フォーカスを復元する場合などです。`.tab_index(...)` と `.tab_stop(...)` で
移動順序を調整できます。

## アクセシビリティ

子がプレーンテキストでない場合、たとえばアイコンのみのボタンでは、`.accessibility_label(...)` でボタンに名前を付けてください。`.selected(true)` は選択時の
スタイルのみを制御します。`.current(true)` は別途、ナビゲーション項目に `aria-current="page"` を公開するため、
選択された見た目が現在のページを意味することはありません。

Toggle、Collapsible と Tooltip のトリガー、CarouselControl、メニューの
トリガーは Button を組み合わせて作られているため、この操作とフォーカスの契約を共有します。
