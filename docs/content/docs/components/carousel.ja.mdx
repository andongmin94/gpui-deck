`CarouselState::new(labels, cx)` は、固定された順序付きのコレクションと選択された
（先頭の）スライドを保持します。選択はデフォルトで範囲が限定され、`.looping(true)` で循環できます。
`.slides_per_view(n)` または `set_slides_per_view(n, window, cx)` は、shadcn の分数のアイテム基準幅のように、
連続する `n` 枚のスライドを表示します。各ステップは 1 枚ずつ移動し、最後のビューは満杯のままなので、
先頭位置は `snap_count()` 個存在し、
`visible_range()` はマウントされているスライドを示します。ループでは最後の満杯のビューと最初のビューの間で循環します。`Carousel::new(id, &state, label)` は
名前付きのフォーカス可能なリージョンを提供し、`CarouselSlide::new(&state, index)` は現在のビューにあるスライドだけをマウントします。
スライドのデータはアプリケーションが保持し、メディア、スライドの幅（たとえば
行内の等しい `flex_1` スライド）、コンテンツ、インジケーターのプレゼンテーションを提供します。
`CarouselControl::previous/next` は、境界で無効になる動作を備えた Button を組み合わせています。

Left/Right は水平リージョン自体にフォーカスがあるときに、Up/Down は垂直リージョンで動作します。Home/End は最初と最後のビューを選択します。スライドの子孫は
独自のキーを保持します。軸と方向は `Carousel` で設定し、すべてのスライドがスワイプに同じ State を使用します。
方向はデフォルトで継承されます。40 論理ピクセルのポインタードラッグは、ジェスチャーごとに 1 回スナップし、
1 回の移動の直後にリリースした場合も含まれます。ビューの縮小などでスライドがビューから外れる場合は、アンマウント前にスライド内のフォーカスを
Carousel のスコープへ戻します。表示されたままのスライド内のフォーカスや、外部の previous/next コントロールのフォーカスは保持されます。
慣性、アニメーション移動、スナップ間の自由スクロールはありません。

`set_autoplay(Some(interval), window, cx)` は間隔ごとに 1 枚ずつ進み、
最後のビューから最初のビューへ循環します。`None` や `is_autoplaying()` で制御と状態の取得を行います。回転は、ポインターが Carousel 上にあるとき、フォーカスが
その内部にあるとき、ウィンドウが非アクティブなとき、またはモーション低減が有効なときに一時停止し、キーボード、スワイプ、
`CarouselControl` によるナビゲーションで停止します。これは Embla のデフォルトの自動再生プラグインと同様です。
ページネーションの `select` などのアプリケーション呼び出しでは停止しません。カタログの "Play slideshow" のように、
目に見える再生/一時停止の Button を描画して、ユーザーが回転を止められるようにしてください（WCAG 2.2.2）。
