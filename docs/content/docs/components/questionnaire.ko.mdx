`QuestionnaireState<A>`는 애플리케이션의 답변 타입과 고정된 선형 흐름을 저장합니다.
`submit_answer`는 답변과 애플리케이션의 검증 결과를 함께 받습니다. 답변이
거부되어도 보관하며, 검증에 성공했을 때만 다음 단계로 넘어갑니다. 검증 오류가
있으면 현재 질문을 그대로 두어 수정할 수 있습니다. `back()`은 답변을 버리지 않고
이전 질문이나 검토 단계로 돌아갑니다. `complete()`는 Review에서 Complete로
전환합니다. 빈 설문은 Review에서 시작합니다.

`Questionnaire::new(id, label)`은 현재 단계를 위한 이름이 있는 시맨틱 그룹을
제공합니다. 기존 편집기와 일반 내비게이션 Button을 조합하고, 상태가 바뀌면 소유한
뷰에 알리며, 편집기를 언마운트하기 전에 포커스를 옮깁니다. 카탈로그는 유지되는
Input 엔티티 두 개, 검증, Back, 검토, 그리고 로컬 대화로 이어지는 완료 과정을
보여 줍니다. 스키마 언어, 분기 엔진, 제출 백엔드, 중복 필드 레지스트리는 없습니다.
