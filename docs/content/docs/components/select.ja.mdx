## 操作と動作

タイムゾーンの一覧を開き、Home、End、矢印キー、または都市名の先頭文字を入力すると、
強調表示された項目が見える位置までスクロールします。Enter で選択を確定できます。
ホイールでほかの項目も閲覧できます。短い一覧は内容に応じた高さで表示され、
`Select::list_max_height(px(144.))` でウィンドウ内での最大の高さを小さくできます。

**Show Asia only** を押すとタイムゾーンの一覧をアジアに絞れます。ソウルの選択は維持され、アジア以外の都市の選択は解除されます。ネイティブの録画例では、同じ API を使用して Presentation プリセットのときにレーザーツールを有効にします。

`SelectState::new(items, cx)` は、順序付きの一意な値の集合、確定された値 1 つ、
そして別個の、ポップアップを開いている間のカーソルを管理します。無効なオプションはスキップされます。
表示のために State を observe し、ユーザーによる確定された変更には `SelectEvent::Change` を購読します。
`set_selected_value(Some(value), window, cx)` は有効な値を設定し、
`None` はクリアします。受け入れられた更新は、通常のフォーカスの復元を使い、ユーザーイベントなしで
ポップアップを閉じます。不明な値や無効な値は、値、保留中のカーソル、ポップアップを変更せずに
false を返します。コントロール全体が無効の間も、アプリケーションからの更新は利用できます。

`set_items(items, window, cx)` は各選択肢の一意な値を使い、確定した選択と強調表示中の選択肢を維持します。一覧を開いている場合はキーボードフォーカスも維持されます。強調表示中の項目が削除または無効化されると、選択中の有効な項目か先頭の有効な項目に移動します。有効な項目がなければ一覧を閉じます。更新による `SelectEvent::Change` の発行はありません。

| 入力 | 結果 |
| --- | --- |
| Enter / Space | ポップアップを開く、またはハイライトされたオプションを確定します |
| Up / Down | 開いて、有効なオプションの間を移動します |
| 開いている間の Home / End | 確定せずに、最初 / 最後の有効なオプションをハイライトします |
| 印字可能な文字 | 閉じている間は一致するオプションを確定し、開いている間はハイライトします |
| Escape | 保留中の選択を破棄し、閉じてトリガーのフォーカスを復元します |

先頭文字入力は、大文字小文字を区別しないラベルの接頭辞に一致し、1 秒後にリセットされます。
同じ文字を繰り返すと、一致するオプションを順に切り替えます。修飾キー付きのショートカット、ネイティブの
文字優先イベント、子孫のエディターからのキーは検索されません。
開閉すると接頭辞はクリアされます。これは編集できない select です。ネイティブのテキストクエリを表示したい場合、グループ化された結果、または複数選択には
Combobox を使用してください。
