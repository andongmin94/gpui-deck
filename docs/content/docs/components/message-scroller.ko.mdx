`MessageScrollerState::new(cx)`는 기존 ScrollHandle과 함께 이전 프레임의 안정적인
메시지 키와 읽기 위치를 소유합니다. `MessageScroller::new(id, &state, cx)`에 제한된
높이를 주고 `.item(stable_id, content)`로 메시지를 하나씩 추가합니다. ID는 대화 안에서
고유해야 하며 각 메시지의 자식 컨트롤 범위도 지정하므로, 순서가 바뀌어도 정체성이
보존됩니다. 다른 대화로 바꿀 때는 새 상태를 만듭니다. 휠/트랙패드 스크롤, 잘라내기,
스크롤바 상호작용은 기존 ScrollArea가 수행합니다.

첫 프레임은 맨 아래에서 시작합니다. 읽는 사람이 맨 아래에 있는 동안에는 메시지 추가,
스트리밍 편집, 크기 변경을 계속 따라갑니다. 읽는 사람이 다른 곳으로 이동하면, 앞쪽에
기록이 추가되거나 이전 항목의 높이가 바뀌어도 처음 보이는 메시지가 픽셀 위치를
유지하며, 보정은 같은 레이아웃 프레임에서 이루어집니다. 고정 기준 메시지를 제거하면
일반적인 네이티브 오프셋 제한이 적용됩니다. 다른 곳에 있는 동안 추가된 메시지는
`unread_count`를 늘리고, `jump_to_latest`는 호출한 쪽 컨트롤의 포커스를 옮기지 않고
따라가기를 재개합니다. 맨 아래로 돌아오면 읽지 않은 수가 지워지며, 크기 변경이나 내용
제거로 같은 프레임에서 맨 아래가 드러나는 경우도 마찬가지입니다. 가상화나 채팅 전송은
없습니다.
