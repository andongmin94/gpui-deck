기존 `MenuState` 엔터티를 가리키는 순서 있는 `MenubarItem` 값으로 `MenubarState`를
만듭니다. 항목마다 `MenubarMenu` 하나를 두어 `Menubar`를 렌더링합니다. 각 메뉴 항목은
트리거와 내용을 제공하면서, 중첩 하위 메뉴와 제어되는 체크/라디오 값을 포함한 공유
Menu 명령 계약을 그대로 유지합니다.

최상위 항목 중 하나만 Tab 스톱입니다. Left/Right는 논리적 순서로 이동하고 Home/End는
양 끝으로 가며, 비활성화된 항목은 건너뜁니다. Down/Up은 첫 번째/마지막 활성 명령에서
엽니다. 메뉴가 열려 있는 동안에는 화살표와 포인터 이동으로 다른 최상위 메뉴로 전환할 수
있으며, 열린 분기는 하나만 남습니다. Escape는 해당 항목으로 돌아갑니다. 카탈로그의
Navigation 뷰가 이 전환을 보여 주고 말단 명령을 유지되는 애플리케이션 상태로 보냅니다.
