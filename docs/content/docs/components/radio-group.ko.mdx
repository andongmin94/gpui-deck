`RadioGroupState::new(items, cx)`는 `RadioItem::new(value, label)`로 이루어진
고정된 순서의 컬렉션으로 한 번만 생성합니다. 값은 고유해야 합니다. 사용할 수 없는
옵션은 `.disabled(true)`로 표시하고, 필요하면 활성화된 `.default_value(value)`를
선택합니다. 일치하는 활성화된 기본값이 없으면 그룹은 선택되지 않은 상태로 시작합니다.

접근 가능한 레이블과 함께 `RadioGroup::new(id, &state)`를 렌더링하고, 각 항목마다
같은 순서로 `RadioOption::new(&state, index)`를 하나씩 렌더링합니다. 각 옵션의
콘텐츠와 스타일은 애플리케이션이 제공합니다. 그룹은 접근성 역할과 방향을 설정하며,
`.axis(Axis::Horizontal)`은 방향 메타데이터를 바꿉니다. 옵션 배치에는
`.flex()` 같은 GPUI 레이아웃 메서드를 별도로 사용합니다.

상태는 `items()`, `selected_index()`, `selected_item()`,
`option_focus_handle(index)`를 노출합니다. 그룹 전체를 비활성화하려면
`set_disabled(disabled, window, cx)`를 사용합니다. 비활성화해도 선택된 값은
유지되며 선택 이벤트는 발생하지 않습니다. 사용자가 다른 값을 선택하면
`RadioGroupEvent::Change(value)`가 한 번 발생합니다. 현재 값을 다시 선택해도
변경 이벤트는 다시 발생하지 않습니다.

`set_selected_value(Some(value), window, cx)`는 활성화된 애플리케이션 값을
적용하고, `None`은 선택을 해제합니다. 알 수 없거나 비활성화된 값은 선택을 바꾸지
않고 false를 반환합니다. 받아들여진 갱신은 사용자 이벤트를 발생시키지 않고 포커스를
유지하며, 그룹 전체가 비활성화된 동안에도 마찬가지입니다. 어떤 옵션이 현재 포커스를
가지고 있으면 포커스가 떠날 때까지 그 옵션이 유일한 Tab 스톱으로 남습니다. 다시
진입할 때는 새로 선택된 옵션 또는 첫 번째 옵션을 사용합니다.
