`InputOtpState::new(length, window, cx)` 创建一个保留的 `InputState`，带有
固定的非零槽位数以及 ASCII 数字/长度验证器。`InputOtp` 通过 `.slot(|slot, window, cx| ...)` 绘制
由应用提供的槽位；每个槽位会收到其索引、字符、活动/选中状态以及禁用/只读标志。
请利用这些信息呈现边框、分组和选择状态。点击槽位
会在同一个编辑器中选择一个位置，并且只有一个输入 Tab 停靠点和
一个原生无障碍持有者。

原生的粘贴、选择、方向键导航、Backspace/Delete 和撤销仍由
现有的编辑器处理。粘贴得到的整个值必须全为数字且长度合适；
文本不会被悄悄截断，也不会分配到多个独立的编辑器中。
`InputOtpEvent` 报告已编辑的 `value` 以及是否所有槽位都已填满。
`set_value` 会验证程序化的替换；`input()` 暴露保留的
编辑器，以便与现有的 Enter/焦点集成，而不改变其验证器。
完成只是一个长度条件，验证仍由应用负责。

目录中的 Forms and feedback 视图使用本地验证码 `742915`：输入完成
会启用 Review session，它会打开一个真实的确认 Drawer；确认后
会先关闭该模态，再向 Toaster 推送一个定时的 Toast，而不匹配的
验证码同样会堆叠一条通知。编辑验证码会清除本地的确认
状态。整个过程不涉及远程验证或传输。
