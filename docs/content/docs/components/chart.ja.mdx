`ChartState` はカテゴリのラベルと `ChartSeries` の値を受け取ります。各系列はカテゴリごとに
有限の値を 1 つ持ちます。保持された State は、表示中の系列、確認中の
カテゴリ、正確な値の説明、0 を含む符号付きの数値範囲を提供します。
すべての系列を非表示にした場合や、すべてが 0 のデータでは、使用可能な `0..1` の範囲になります。この範囲は
表示状態またはレイアウトが変わるまで保持され、ポイントの正規化でデータセットを再スキャンすることはありません。

`ChartLayout` は同じデータがプロットをどう共有するかを選択し、`set_layout` は
表示状態と確認状態を保持します。

- `Grouped`（デフォルト）は、等間隔のカテゴリ帯の上に系列を並べて配置します。
- `Stacked` は、正の値と負の値を 0 から別々に積み上げます。範囲は
  各カテゴリの表示中の合計をカバーし、`stack_span(series, category)` は
  表示されているセグメントの開始値と終了値を返します。
- `Pie` は、各カテゴリに、表示中の系列の非負の合計に比例した大きさのスライスを 1 つ与えます。
  `pie_slices` は開始/終了のターンを返し、合計が 0 または負の場合は
  空のスライスになります。
- `Radar` は、カテゴリを等間隔のスポーク（`radar_turn`）に配置し、半径は
  Grouped と同様に正規化されます。

放射状のターンは上から時計回りに進み、RTL では反時計回りに反転します。
`Chart` は名前付きのプロットフォーカスリージョンを提供します。Left/Right/Home/End はすべてのレイアウトで
カテゴリを確認します。ポインターの移動は、Grouped/Stacked では水平方向の帯で、Pie/Radar では中央の最大の円の内側の角度で
確認します。その円の外側やスライス上にないポインターは、現在の確認状態を保ちます。
確認/表示状態のイベントを発行しますが、色や描画パスは規定しません。

コピーして使える `examples/recipes/chart.rs` は、この動作を土台に、GPUI の canvas による
折れ線、グループ棒、面、積み上げ棒/面、円、ドーナツ、レーダーのプロット、軸またはスポークのラベル、円グラフのカテゴリキー、Toggle ベースの系列の凡例、正確な値の
表示、同じ完全なデータセットを含む通常の Table を構築しています。`ChartKind::layout` は
各種類が描画する State のレイアウトを示します。カタログの Media and data ビューは、
種類や方向を切り替えるときに両方を設定し、凡例と確認状態を保持します。プロットの
ジオメトリ、パレット、数値の書式設定は利用側が管理します。このカテゴリ向けの
契約は、時間/対数スケール、スライスごとの凡例選択、ズーム、
ストリーミングデータの取り込み、独立したレンダリングエンジンを提供しません。

レシピをコピーしたら、`ChartRecipe::new` にプロットのアクセシブル名、データ全体を示す表の名前、
カテゴリ列の見出しを渡します。既定の目盛りは小数値を保持します。`format_value` で単位を指定すると、
目盛り、現在値の表示、ネイティブのアクセシビリティの値、表のセルに反映されます。

```rust
ChartRecipe::new("latency", &state, ChartKind::Line, Direction::Ltr,
    "リクエストの応答時間", "すべての応答時間の測定値", "ルート")
    .format_value(|value| format!("{value} ms"))
```
