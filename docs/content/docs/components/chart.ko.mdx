`ChartState`는 범주 레이블과 `ChartSeries` 값을 받습니다. 각 시리즈는 범주마다
유한한 값 하나를 가집니다. 유지되는 상태는 보이는 시리즈, 검사 중인 범주, 정확한 값
설명, 0을 포함하는 부호 있는 숫자 범위를 제공합니다. 모든 시리즈를 숨기거나 모든 값이
0이면 사용 가능한 `0..1` 범위가 됩니다. 범위는 가시성이나 레이아웃이 바뀔 때까지
유지되며, 포인트를 정규화해도 데이터셋을 다시 훑지 않습니다.

`ChartLayout`은 같은 데이터가 플롯을 어떻게 나눠 쓸지 선택하며, `set_layout`은
가시성과 검사 상태를 유지합니다.

- `Grouped`(기본값)는 균등한 간격의 범주 구간 위에 시리즈를 나란히 배치합니다.
- `Stacked`는 양수와 음수 값을 0에서부터 따로 쌓습니다. 범위는 각 범주의 보이는
  합계를 포함하며, `stack_span(series, category)`는 보이는 구간의 시작 값과 끝 값을 줍니다.
- `Pie`는 범주마다 보이는 시리즈의 음수가 아닌 합계에 비례하는 조각 하나를 줍니다.
  `pie_slices`는 시작/끝 회전량을 반환하며, 합계가 0이거나 음수이면 조각이 비어 있습니다.
- `Radar`는 범주를 균등한 간격의 바퀴살(`radar_turn`)에 배치하며, 반지름은
  Grouped와 같은 방식으로 정규화됩니다.

원형 회전은 위쪽에서 시계 방향으로 진행하며, RTL에서는 반시계 방향으로 뒤집힙니다.
`Chart`는 이름이 있는 플롯 포커스 영역을 제공합니다. 모든 레이아웃에서
Left/Right/Home/End로 범주를 검사합니다. 포인터 이동은 Grouped/Stacked에서는 가로
구간 기준으로, Pie/Radar에서는 가장 큰 중앙 원 안에서 각도 기준으로 검사합니다.
포인터가 그 원 밖에 있거나 어떤 조각 위에도 없으면 현재 검사 상태가 유지됩니다.
색상이나 그리기 경로를 정하지 않고 검사/가시성 이벤트를 내보냅니다.

복사해 쓸 수 있는 `examples/recipes/chart.rs`는 이 동작 위에 GPUI canvas로 선, 그룹
막대, 영역, 누적 막대/영역, 파이, 도넛, 레이더 플롯을 그리고, 축 또는 바퀴살 레이블,
파이 범주 키, Toggle 기반 시리즈 범례, 정확한 값 표시, 같은 전체 데이터셋을 담은 일반
Table을 더합니다. `ChartKind::layout`은 각 종류가 그리는 상태 레이아웃을 가리킵니다.
카탈로그의 Media and data 뷰는 종류나 방향을 바꿀 때 둘 다 설정하고 범례/검사 상태를
유지합니다. 플롯 기하, 팔레트, 숫자 서식은 소비자가 맡습니다. 이 범주형 계약은
시간/로그 축, 조각별 범례 선택, 확대/축소, 스트리밍 데이터 수집, 별도의 렌더링 엔진을
제공하지 않습니다.

레시피를 복사할 때 `ChartRecipe::new`에 플롯의 접근성 이름, 전체 데이터 표의 이름,
범주 열 제목을 전달합니다. 기본 눈금은 소수 값을 유지합니다. `format_value`로
단위를 지정하면 눈금, 현재 값 표시, 네이티브 접근성 값, 표의 셀에 함께 적용됩니다.

```rust
let state = cx.new(|cx| ChartState::new(
    ["Search", "Cart", "Pay"],
    [
        ChartSeries::new("Median", [0.12, 0.08, 0.18]),
        ChartSeries::new("P95", [0.32, 0.2, 0.4]),
    ],
    cx,
));

ChartRecipe::new("latency", &state, ChartKind::Line, Direction::Ltr,
    "요청 지연 시간", "전체 지연 시간 측정값", "경로")
    .format_value(|value| format!("{value} s"))
```
