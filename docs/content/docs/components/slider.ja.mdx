`SliderState::new(min..=max, step, [values...], cx)` を一度だけ作成します。値が 1 つなら
つまみ 1 つのスライダーになり、2 つの値は範囲を表し、それ以上の値は順序付きの
停止点を追加します。空でないコレクションがつまみの数を決めます。範囲と値は
有限で、`min < max`、`step` は正でなければなりません。値は丸められ、
最小値から始まるステップのグリッドに合わせられます。範囲は両端を含みます。

名前付きのグループとレールとして `Slider::new(id, &state).accessibility_label(...)` を描画します。
トラックとフィル、そして値ごとに 1 つの
`SliderThumb::new(&state, index).accessibility_label(...)` を順序どおりに指定します。
各つまみは、ネイティブの Slider ロール、フォーカス、キー、値のアクションを持ちます。範囲の
両端には、"Trim start" と "Trim end" のように異なる名前を付けてください。`percentage(index)` は、
そのつまみの位置を 0 から 1 で返します。ルートの範囲が移動のレールを定義します。つまみの
中心をルートのその割合の位置に置き、アプリケーションのつまみのサイズの半分だけオフセットします。
サンプルは、操作しやすい高さのヒット領域と、その内側の中央に配置した細いトラックを使用しています。
色もコントロールの寸法も、ライブラリは強制しません。

State は `values`、`min_value`、`max_value`、`step_value`、`percentage`、
`thumb_focus_handle(index)`、`is_disabled` を公開します。プログラムによる更新には
`set_thumb_value(index, value, window, cx)` または `set_values(values, window, cx)` を、
ユーザーの操作の制御には `set_disabled(disabled, window, cx)` を使用します。
無効の間もプログラムによる更新は可能です。個々の
つまみは、同一性を入れ替えることなく隣のつまみで止まり、等しい値は
許可されます。`SliderEvent::Change(values)` は、正規化された値が変化したときに
順序付きの完全な値を 1 回通知します。アプリケーションの視覚表現を更新するには State を observe します。

レールの押下は最も近いつまみを選び、ドラッグはリリースするまで、レールの外でも
そのつまみを保ちます。`axis(Axis::Vertical)` は最小値を下に配置し、
水平方向の値は論理的な方向に従います。各つまみは、アクセシブルな名前、向き、現在の値、ステップ、
隣のつまみによって制限された数値の範囲を公開します。つまみのフォーカス表示は
アプリケーションが指定します。

| 入力 | 動作 |
| --- | --- |
| Left / Down | 1 ステップ減らします |
| Right / Up | 1 ステップ増やします |
| Home / End | フォーカスされたつまみの許容される最小値 / 最大値に設定します |
| PageDown / PageUp | 10 ステップ減らす / 増やします |
| Tab / Shift-Tab | 有効な各つまみを値の順に巡り、その後グループから離れます |

無効なスライダーはユーザーによる変更を無視し、Tab ではスキップされます。フォーカス中に
無効になったスライダーは、Tab で離れられるよう、しばらくフォーカスのバインディングを保ちます。
セッションのプレビューはつまみ 1 つを使用します。カタログのメディアトリミングのコントロールは、2 つの
独立した端を使用し、水平/垂直のジオメトリと RTL を切り替えます。
