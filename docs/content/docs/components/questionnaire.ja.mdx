`QuestionnaireState<A>` は、アプリケーションの回答の型と固定された線形の
フローを保持します。`submit_answer` は回答とアプリケーションの検証結果を受け取り、
拒否された場合でも回答を保持し、検証に成功した後でのみ進みます。検証エラーがあっても、現在の質問は修正のために利用できる状態のままです。`back()` は
回答を破棄せずに前の質問/確認へ戻り、`complete()` は
Review から Complete へ遷移します。空のアンケートは Review から始まります。

`Questionnaire::new(id, label)` は、現在の段階のための名前付きのセマンティックな
グループを提供します。既存のエディターと通常のナビゲーション用 Button を組み合わせ、
状態の変更後に所有するビューへ通知し、エディターをアンマウントする前にフォーカスを移動してください。
カタログは、保持された 2 つの Input エンティティ、検証、Back、確認、ローカルの会話への
完了を示します。スキーマ言語、分岐エンジン、送信バックエンド、重複するフィールドレジストリはありません。
