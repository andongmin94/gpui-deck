---
title: すべてのコンポーネント
description: "ヘッドレスのライブラリファミリー: 動作、状態、フォーカス、アクセシビリティはライブラリが、プレゼンテーションはあなたのコードが担当します。"
---

<Cards>
  <Card title="Accordion" href="/ja/docs/components/accordion/">
    単一または複数のセクション展開、ヘッダーナビゲーション、無効な項目、フォーカス中パネルの閉鎖に対応します。
  </Card>
  <Card title="Alert Dialog" href="/ja/docs/components/alert-dialog/">
    アラートのセマンティクスとバックドロップによる閉鎖のブロックを備えた、Dialog のモーダルライフサイクルです。
  </Card>
  <Card title="Breadcrumb" href="/ja/docs/components/breadcrumb/">
    名前付きナビゲーション、順序付きのパス項目、ネイティブの現在ページメタデータを提供します。
  </Card>
  <Card title="Button" href="/ja/docs/components/button/">
    ポインターとキーボードによる操作、無効状態、フォーカス、アクセシブルな名前とロール、任意の現在ページメタデータを提供します。
  </Card>
  <Card title="Calendar" href="/ja/docs/components/calendar/">
    単一/複数/範囲の日付選択、独立したフォーカス、日付の無効化ルール、設定可能な週の開始日、範囲を限定したナビゲーション、RTL に対応します。
  </Card>
  <Card title="Carousel" href="/ja/docs/components/carousel/">
    先頭スライドと 1 つ以上のビューあたりのスライド数、オプトインで一時停止する自動再生、範囲限定/ループのナビゲーション、離散的なスワイプ、RTL、フォーカスの復元に対応します。
  </Card>
  <Card title="Chart" href="/ja/docs/components/chart/">
    カテゴリ系列、グループ/積み上げ/円/レーダーのレイアウト、表示中の系列の値域、直線的または角度によるポイントの確認、ネイティブでの正確な値の公開に対応します。
  </Card>
  <Card title="Checkbox と Switch" href="/ja/docs/components/checkbox/">
    制御された未チェック/チェック済み/混在の状態、操作、無効状態、フォーカスに対応します。
  </Card>
  <Card title="Collapsible" href="/ja/docs/components/collapsible/">
    単一の開閉、アクティブ時のみのコンテンツ、無効なトリガー、コンテンツを閉じたときのフォーカスに対応します。
  </Card>
  <Card title="Combobox" href="/ja/docs/components/combobox/">
    編集可能な単一/複数選択、グループ化された検索結果、差し替え可能なオプション、キーボード/ポインターによる確定、下書きのキャンセルに対応します。
  </Card>
  <Card title="Command" href="/ja/docs/components/command/">
    ランク付けされたあいまいテキスト検索、有効な結果のナビゲーション、ポインター/Enter によるアクション発行、ハイライトされた結果へのスクロールに対応します。
  </Card>
  <Card title="Context Menu" href="/ja/docs/components/context-menu/">
    セカンダリクリック、タッチの長押し、キーボードによる表示、ポインター位置への配置、および共有メニューツリーのコマンド、ナビゲーション、閉じる動作、フォーカスに対応します。
  </Card>
  <Card title="Date Picker" href="/ja/docs/components/date-picker/">
    Popover 内でのカレンダー選択、選択日または保持されたカーソルへの初期フォーカス、単一/完成した範囲での閉鎖、閉じる動作、無効状態、入力された ISO/相対日付の解析に対応します。
  </Card>
  <Card title="Dialog" href="/ja/docs/components/dialog/">
    開閉状態、ネイティブのモーダルメタデータ、背景の入力の遮断、初期フォーカス、閉じる動作、フォーカスの復元に対応します。
  </Card>
  <Card title="Direction" href="/ja/docs/components/direction/">
    スコープ付きの論理的な方向、ネストした上書き、一貫した水平方向のキー/ポインターのジオメトリに対応します。
  </Card>
  <Card title="Drawer" href="/ja/docs/components/drawer/">
    4 辺からドラッグして閉じるモーダルです。上下のパネルには停止位置を指定できます。
  </Card>
  <Card title="Dropdown Menu" href="/ja/docs/components/dropdown-menu/">
    通常、チェック/混在/ラジオ、ネストしたサブメニューのセマンティクス、ナビゲーション、リーフのディスパッチ、閉じる動作、フォーカスに対応します。
  </Card>
  <Card title="Field" href="/ja/docs/components/field/">
    Input/Textarea ベースのコントロール向けのラベルフォーカス、ヘルプ/エラーの説明、required/invalid メタデータに加え、Checkbox、Switch、RadioGroup、Select 向けの ControlField を提供します。
  </Card>
  <Card title="Hover Card" href="/ja/docs/components/hover-card/">
    ホバーによる遅延表示のリッチプレビュー、タッチの長押しプレビュー、トリガーからカードへのポインター移動、フォーカスを移さないフォーカスプレビュー、閉じる動作に対応します。
  </Card>
  <Card title="Input OTP" href="/ja/docs/components/input-otp/">
    1 つの数値エディター、ネイティブの選択/貼り付け/削除/元に戻す、桁スロット、完了イベントを提供します。
  </Card>
  <Card title="Label" href="/ja/docs/components/label/">
    クリックすると既存のコントロールにフォーカスする名前付きのネイティブテキストラベル。明示的な無効フラグを持ち、追加の Tab ストップはありません。
  </Card>
  <Card title="Menubar" href="/ja/docs/components/menubar/">
    1 つのトップレベルのフォーカス入口、メニューの切り替え、表示、共有のコマンドツリーを提供します。
  </Card>
  <Card title="Message Scroller" href="/ja/docs/components/message-scroller/">
    最下部への追従、キー付き履歴のアンカー、未読数、最新へのジャンプを提供します。
  </Card>
  <Card title="Navigation Menu" href="/ja/docs/components/navigation-menu/">
    連携する開閉、ローヴィングフォーカス、移動先 Link のアクティブ化を提供します。
  </Card>
  <Card title="Popover" href="/ja/docs/components/popover/">
    非モーダルの開閉状態、角または衝突を考慮した辺/整列の配置、フォーカス、外側クリックでの閉鎖、Escape に対応します。
  </Card>
  <Card title="Progress" href="/ja/docs/components/progress/">
    制御されたパーセンテージまたは不確定の進捗、アクセシブルな名前と数値範囲を提供します。
  </Card>
  <Card title="Questionnaire" href="/ja/docs/components/questionnaire/">
    線形の質問/確認/完了のフロー、検証された回答、Back に対応します。
  </Card>
  <Card title="Radio Group" href="/ja/docs/components/radio-group/">
    単一選択、プログラムによる設定/クリア、1 つの Tab ストップ、矢印キーによるナビゲーション、無効なオプション、フォーカスに対応します。
  </Card>
  <Card title="Resizable" href="/ja/docs/components/resizable/">
    複数パネルのサイズ、連鎖するポインター/キーボードでのリサイズ、パネルごとの比率とピクセルの制限、折りたたみ可能なパネル、保持されるサイズ、ネイティブのスプリッターのセマンティクスに対応します。
  </Card>
  <Card title="Scroll Area" href="/ja/docs/components/scroll-area/">
    ネイティブのビューポート、既存のオーバーレイスクロールバー、保持されるオフセット、有効な軸での子孫の表示領域への移動に対応します。
  </Card>
  <Card title="Select" href="/ja/docs/components/select/">
    固定された単一選択、バッファされた先頭文字入力、Home/End と矢印キーによるナビゲーション、無効なオプション、確定、フォーカスに対応します。
  </Card>
  <Card title="Separator" href="/ja/docs/components/separator/">
    セマンティックまたは装飾的な区切り。水平/垂直の向きに対応します。
  </Card>
  <Card title="Slider" href="/ja/docs/components/slider/">
    1 つ以上の順序付きの数値、範囲を限定したステップ、つまみごとのフォーカスとアクセシビリティ、キーボード/ポインターによる調整、無効状態、垂直と RTL のジオメトリに対応します。
  </Card>
  <Card title="Table" href="/ja/docs/components/table/">
    共有される固定/可変の列、ヘッダー/本体/フッターの構造、ネイティブの行/セルのセマンティクス、行の選択、ヘッダーのソートメタデータを提供します。
  </Card>
  <Card title="Tabs" href="/ja/docs/components/tabs/">
    アクティブなパネル、1 つのタブリストストップ、自動または手動のアクティブ化、向きに応じたキー、無効なタブに対応します。
  </Card>
  <Card title="Textarea" href="/ja/docs/components/textarea/">
    同じエンジンによる複数行の編集、保持されるテキスト、折り返し、通常のフォームの Tab 移動に対応します。
  </Card>
  <Card title="Toast" href="/ja/docs/components/toast/">
    保持される存続期間、ホバー/フォーカス/ウィンドウによる一時停止、安全な閉鎖、表示数の上限を持つ積み重ね型の Toaster を提供します。
  </Card>
  <Card title="Toggle と Toggle Group" href="/ja/docs/components/toggle/">
    Button の操作、フォーカス、無効時の動作に基づく、制御された押下状態を提供します。
  </Card>
  <Card title="Tooltip" href="/ja/docs/components/tooltip/">
    Button のホバー/フォーカス時の、プレーンテキストのネイティブな説明と、任意の操作できないリッチコンテンツ、遅延ホバー、Escape による閉鎖、ネイティブの Tooltip の配置に対応します。
  </Card>
</Cards>
