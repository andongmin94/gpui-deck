`Textarea::new(&state)`는 기존 여러 줄 편집 엔진을 렌더링합니다.
`TextareaState::new(window, cx)`는 한 번만 생성하며, 고정된 행 수에는 `.rows(3)`,
범위가 있는 자동 확장에는 `.auto_grow(min, max)`를 사용합니다. 상태는 플레이스홀더/
기본 텍스트와 소프트 줄 바꿈도 지원합니다. 선택, 실행 취소, 스크롤, 클립보드,
네이티브 텍스트 입력 인터페이스는 모두 같은 유지되는 엔티티에 남습니다.

`Role::MultilineTextInput`과 접근 가능한 레이블을 담은 `InputAccessibility`를
지정합니다. 애플리케이션이 소유하는 프레임을 위해 렌더러를 `InputBase`로 감싸고,
프레임에 `.role(None::<Role>)`과 `.semantic_owner::<Textarea>(state.entity_id())`를
설정해 텍스트 엔티티가 유일한 네이티브 시맨틱/포커스 소유자가 되도록 합니다. 예제는
한 줄 필드와 여러 줄 메모에 같은 애플리케이션 팔레트를 사용합니다.

Enter는 기본적으로 줄 바꿈을 삽입합니다. 행 기반 textarea와 자동 확장 textarea
모두에서 Tab과 Shift-Tab은 일반적인 폼 내비게이션을 따르며, 코드 편집기식 들여쓰기는
별개입니다. `set_disabled(bool, cx)`는 편집과 일반적인 Tab 진입을 막습니다.
포커스된 상태에서 비활성화된 필드는 Tab으로 떠날 수 있도록 바인딩을 유지합니다.
다시 활성화하면 진입이 복원됩니다. `set_readonly(bool, cx)`는 포커스와 선택을
유지하면서 편집을 막습니다. 프로그래밍 방식의 `set_value`는 애플리케이션 갱신을
위해 계속 사용할 수 있습니다. 네이티브 입력 노드는 사용 가능한 편집 액션과 함께
읽기 전용 상태를 명시적으로 노출합니다.

접는 섹션, 탭 패널, Dialog를 닫아도 텍스트가 보존되도록 상태를 그 렌더 경로 바깥에
둡니다. 예제는 설정 대화 상자를 닫았다가 다시 열어도 Session notes를 유지합니다.
