HoverCard は、Button の通常のアクションに対する、リッチで操作できないプレビューを提供します。
安定したトリガーのフォーカスハンドルを保持し、
`HoverCardState::new(&trigger_focus, window, cx)` を作成します。利用側を再描画するには State を
observe します。任意の `.with_delays(open_duration, close_duration)` は、マウント前のポインターの
進入と退出の遅延を設定します。デフォルトは 500 ms と 200 ms です。

```rust
HoverCard::new("preset-preview", &preview)
    .accessibility_label("Recording preset preview")
    .offset(px(6.))
    .trigger(|button| {
        button
            .accessibility_label("Recording preset. Edit settings")
            .on_click(open_settings)
            .child("Preset: Balanced")
    })
    .content(preview_surface)
```

トリガーのビルダーは Button のアクションを保持し、その外観を指定します。
State は自身のフォーカスハンドルと無効状態を管理します。プレビューと Button を
連動させるには `set_disabled` を使用します。HoverCard の `Styled` メソッドはホストのフレームに
適用されます。アプリケーションが指定するコンテンツには別途スタイルを適用し、既存の Popup のジオメトリには
`.anchor(...)` と `.offset(...)` を使用してください。

| 入力 | 動作 |
| --- | --- |
| ポインターがトリガーに入る | フォーカスを移さずに、進入の遅延後に開きます |
| ポインターがトリガーとカードの両方から出る | 退出の遅延後に閉じます。ただしトリガーがキーボードフォーカスを保持している場合を除きます |
| ポインターがカードに入る、またはトリガーに戻る | 遅延されていた閉鎖をキャンセルします |
| キーボードフォーカスがトリガーに入る | すぐに開きます。フォーカスは Button に残ります |
| Escape | 表示中のプレビューを閉じ、現在の進入の間は再表示を抑制します |
| クリック / Enter / Space | プレビューを閉じます。Button またはクリックされたコントロールは通常のアクションを実行します |
| フォーカスの変更 / ウィンドウの非アクティブ化 | フォーカスを移さずに閉じます |

閉じる遅延により、ポインターがトリガーとカードの間の隙間を横切れます。キーボードで開いた
プレビューは、ポインターが離れても、ブラーまたは明示的な閉鎖まで残ります。
Escape はフォーカスをその場に残し、別のフレームが描画されたり、同じトリガー内でポインターが動いたりしただけでは
カードを再表示しません。新たなトリガーへの進入やキーボードフォーカスで再び表示できます。まだ表示されていない
保留中のプレビューをキャンセルしても、Escape は周囲のサーフェスが利用できる状態のままです。

State のメソッドは `is_open`、`is_disabled`、`focus_handle`、
`close(window, cx)`、`set_disabled(disabled, window, cx)` です。明示的な閉鎖は
現在の進入を抑制します。再び有効にすると、次の進入またはフォーカスを待ちます。
アンマウントすると遅延された処理がキャンセルされ、保持されていた表示状態がクリアされます。マウントされた
Escape の購読は、そのウィンドウにのみ属します。

Popup は配置、ビューポートへの制限、遅延描画、オクルージョンを管理します。表示される
プレビューは Tab ストップを持たない補助的な Tooltip サーフェスであり、フォーカストラップを
開くことはありません。`accessibility_label` はそのサーフェスに名前を付けます。重要な
情報は、ポインターのプレビューだけでなく、Button のアクセシブルな説明や通常の
移動先でも利用できるようにしてください。インタラクティブなコンテンツは
Popover に置きます。タッチにはホバーがありません。トリガーの長押しは Button をアクティブ化せずに
すぐにプレビューを開き、次にどこかを押すと閉じます。グローバルな
ホバープロバイダーは提供されません。

サンプルは、現在の録画プリセット、録画日、ノートの状態をプレビューします。同じ Button をクリックするか Enter を押すと
設定の Dialog が開き、閉じると Button にフォーカスが戻ります。
