**Profile details**를 열면 **Close** 버튼으로 포커스가 이동합니다. Escape를 누르거나 Close를 선택하면 처음 버튼으로 포커스가 돌아옵니다.

## 동작

`Dialog::new(&state)`는 모달입니다. 네이티브 모달 메타데이터를 노출하고, 장식용
배경막이 없어도 배경의 포인터/휠 입력을 차단합니다. 접근 가능한 이름, 팝업, 시각적
배경막은 애플리케이션이 제공합니다. Tab과 Shift-Tab이 활성 대화상자 안에 머물도록
Root 아래에 마운트해 둡니다.

열기, 초기 포커스, Escape, 포커스 복귀는 기존 상태가 소유합니다. 배경막을 제공하고
활성화하면 배경막을 눌러 닫을 수 있습니다. 이 시각 요소를 생략해도 배경 컨트롤은
여전히 비활성 상태로 유지됩니다. Popover는 비모달이며 모달 플래그를 설정하지 않습니다.
AlertDialog, Drawer, Sheet는 Dialog를 재사용합니다.
