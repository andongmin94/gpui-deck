`Dialog::new(&state)` はモーダルです。ネイティブのモーダルメタデータを公開し、
装飾用のバックドロップがなくても背景のポインター/ホイール入力をブロックします。
アクセシブルな名前、ポップアップ、視覚的なバックドロップはアプリケーションが提供します。Tab と Shift-Tab が
アクティブなダイアログ内に留まるよう、Root の下にマウントしたままにしてください。

既存の State が、開く動作、初期フォーカス、Escape、復帰先のフォーカスを管理します。バックドロップの
押下による閉鎖は、バックドロップが提供され有効な場合に使えます。この視覚的な要素を
省略しても、背景のコントロールは無効なままです。Popover は非モーダルであり、
モーダルフラグを設定しません。AlertDialog、Drawer、Sheet は Dialog を再利用します。
