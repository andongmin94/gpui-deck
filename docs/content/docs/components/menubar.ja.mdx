既存の `MenuState` エンティティを参照する、順序付きの `MenubarItem` の値から `MenubarState` を構築します。
項目ごとに 1 つの `MenubarMenu` を持つ `Menubar` を描画します。各メニュー
エントリはトリガーとコンテンツを提供しつつ、ネストしたサブメニューや制御されるチェック/ラジオの値を含む、
共有の Menu コマンドの契約を保持します。

Tab ストップになるのは、トップレベルの項目 1 つだけです。Left/Right は論理的な順序で移動し、
Home/End は両端に到達し、無効なエントリはスキップされます。Down/Up は最初/最後の
有効なコマンドを開きます。メニューが開いている間は、矢印キーとポインターの移動で
別のトップレベルのメニューに切り替えられ、開いたままの枝は 1 つだけです。Escape は
対応するエントリに戻ります。カタログの Navigation ビューはこれらの遷移を示し、
リーフのコマンドを保持されたアプリケーションの State へ渡します。
