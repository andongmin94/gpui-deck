`SelectState::new(items, cx)`는 고정된 순서의 고유한 값 집합, 확정된 값 하나,
그리고 별도의 열린 팝업 커서를 소유합니다. 비활성화된 옵션은 건너뜁니다. 화면
표현에는 상태를 관찰하고, 사용자가 확정한 변경에는 `SelectEvent::Change`를
구독합니다. `set_selected_value(Some(value), window, cx)`는 활성화된 값을
설정하고, `None`은 값을 지웁니다. 받아들여진 갱신은 사용자 이벤트 없이 팝업을
닫으며 일반적인 포커스 복원을 사용합니다. 알 수 없거나 비활성화된 값은 값, 대기
중인 커서, 팝업을 바꾸지 않고 false를 반환합니다. 컨트롤 전체가 비활성화된
동안에도 애플리케이션 갱신은 가능합니다.

| 입력 | 결과 |
| --- | --- |
| Enter / Space | 팝업을 열거나, 강조된 옵션을 확정 |
| Up / Down | 팝업을 열고 활성화된 옵션 사이를 이동 |
| 열린 상태에서 Home / End | 확정하지 않고 첫 번째 / 마지막 활성화된 옵션을 강조 |
| 출력 가능한 문자 | 닫힌 상태에서는 일치하는 옵션을 확정하고, 열린 상태에서는 강조 |
| Escape | 대기 중인 선택을 버리고, 닫은 뒤 트리거 포커스를 복원 |

타입어헤드는 대소문자를 구분하지 않고 레이블 접두사를 비교하며, 1초 후 초기화됩니다.
같은 글자를 반복하면 일치하는 옵션을 순환합니다. 수정자 키가 포함된 단축키, 네이티브
문자 우선 이벤트, 하위 편집기에서 온 키는 검색하지 않습니다. 열거나 닫으면 접두사가
지워집니다. 이것은 편집할 수 없는 select입니다. 보이는 네이티브 텍스트 쿼리, 그룹화된
결과, 다중 선택이 필요하면 Combobox를 사용합니다.
