Table は列を一度だけ定義し、それをヘッダー、本体、フッターに適用します。
各行は、列ごとにちょうど 1 つのセルを提供しなければなりません。安定したトラックには固定幅を、
残りの幅の分配には正の可変の重みを使用します。

```rust
Table::new(
    "sessions",
    [TableColumn::fixed(px(180.)), TableColumn::flex(1.)],
)
.accessibility_label("Sessions")
.w_full()
.header(
    TableRow::new("sessions-header")
        .cell(TableCell::new("session-heading").p_2().child("Session"))
        .cell(TableCell::new("date-heading").p_2().child("Date")),
)
.row(
    TableRow::new("session-1")
        .cell(TableCell::new("session-1-name").row_header(true).p_2().child("Workshop"))
        .cell(TableCell::new("session-1-date").p_2().child("2026-11-09")),
)
.caption(TableCaption::new("sessions-caption").child("Scheduled sessions"))
```

`header` と `footer` はそれぞれ 1 行を受け付けます。本体の行は `row` または
`rows` で追加します。`TableRow::cells` はイテレーターも受け付けます。空の本体も有効なので、
アプリケーションは、空の状態の説明を表の横に描画できます。

すべてのパーツが `Styled` を実装しています。セルとキャプションは任意の子要素を受け付けます。
アプリケーションはセルに既存の Button や Checkbox を置けます。構造的な
テーブルのパーツは Tab ストップを追加せず、それらのコントロールの操作を妨げません。
Table は行の水平レイアウトを管理します。行に水平のパディング、マージン、隙間を追加するのではなく、
セルの内側に余白を設けてください。セルのスタイルは内側のコンテンツ面に適用されるため、
ヘッダーと本体のパディングが異なっても、共有される外側の列幅は保たれます。

| パーツ | ネイティブのセマンティクス |
| --- | --- |
| Table | Table、行数、列数、明示的なアクセシブルなラベル |
| ヘッダー/本体/フッター | RowGroup |
| 行 | Row と 0 始まりのインデックス |
| ヘッダーセル | 行/列のインデックスを持つ ColumnHeader |
| 通常のセル | 行/列のインデックスを持つ Cell |
| `row_header(true)` を持つセル | RowHeader。ただし列ヘッダーの行に属する場合を除きます |
| キャプション | フォーカスアクションのない Caption |

インデックスにはヘッダーとフッターが含まれます。表示されるキャプションは、自動的には
テーブルに名前を付けません。`accessibility_label` を別途指定してください。セルも、表示される内容が名前を提供しない場合に備えて、
明示的なアクセシブルなラベルを受け付けます。

これは、セルのナビゲーションやデータコントローラーを持たない、通常のテーブルです。行や
列のスパン、固有の列サイズの自動調整、ソート、フィルタリング、ページネーション、
選択の管理、仮想化は提供されません。`TableRow::selected` と
`TableCell::sort_direction` は、アプリケーションが管理する選択とソートを
ネイティブのメタデータに反映しますが、データ操作は行いません。データ操作は、実際のアプリケーションが必要とするときに、
この構造の上に組み合わせてください。

コピーして使える [DataTable レシピ](../recipes/data-table.mdx)は、テキストの
フィルタリング、単一列のソート、ページネーション、ページ/行のチェックボックスによる選択、列の
表示切り替え、空の状態からの復帰、安定した ID による行アクションを追加します。ネイティブのサンプルは、これを使って録画プリセットを閲覧して適用します。
そのクエリとページの状態は、Table の外にあるアプリケーションが管理します。
