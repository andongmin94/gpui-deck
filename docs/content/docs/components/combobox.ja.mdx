プレビューで `s` を入力して Enter を押すと SvelteKit が選択されます。矢印キーは表示された検索順位に沿って移動し、無効な項目を飛ばします。

順序付きで一意な `SearchItem::new(value, label)` エントリから
`ComboboxState::new(items, window, cx)` を構築します。`.keywords(...)` はエイリアスを追加し、
`.disabled(true)` は利用できない選択肢を示し、`.group(label)` は名前付きの
結果グループを割り当てます。各グループの項目は、ソース順で連続させてください。
共有の Command エンジンがネイティブのクエリ編集、フィルタリング、ハイライト、
スクロールを担当し、Combobox は確定した選択とポップアップのライフサイクルを担当します。

デフォルトは単一選択です。`.multiple(true)` で複数の確定値を許可します。
`set_selected_values([values...], window, cx)` はユーザーイベントなしで選択を初期化または
置換し、空のイテレーターで選択をクリアします。不明な値や無効な値、および単一モードでの
2 つ以上の異なる値は拒否されます。アプリケーションでの表示には
`selected_indices()`、`is_selected(index)`、`selected_items(cx)`、`selected_values(cx)` を読み取ります。
ユーザーの操作は、選択が変わった場合にのみ、項目の順序で `ComboboxEvent::Change(values)` を発行します。

`Combobox::new(id, &state).input(|input| ...).content(surface)` を描画します。input
ビルダーは、そのフレーム、名前、プレースホルダー、`InputStyles` を管理します。名前付きの
`ComboboxList` は `ComboboxOption` の子を `visible_indices(cx)` の順序で含み、
必要に応じて `ComboboxGroup::new(id, &state, label)` のラッパーの内側に置きます。グループ
名は `visible_groups(cx)` で、一致する項目のインデックスは
`visible_group_indices(Some(label), cx)` で取得します。`None` はグループ化されていない項目を返します。各グループは
名前付きのネイティブの Group と Heading を提供し、`.heading(...)` はその見出しにスタイルを適用します。
空のグループは表示されなくなり、見出しはキーボードナビゲーションに含まれません。リストには
高さの上限を与え、空の場合のテキストはリストの外に置いてください。

| 操作 | 結果 |
| --- | --- |
| ポインターまたは矢印キーで閉じた input を開く | すべてのオプションを表示し、最初に選択済みの、または有効な選択肢をハイライトします |
| 入力 | 確定値を変えずに候補を絞り込みます |
| Up / Down | グループをまたいで有効な結果を移動します |
| Enter / 結果のクリック（単一モード） | 1 つの選択肢を確定し、候補を閉じてそのラベルを復元します |
| Enter / 結果のクリック（複数モード） | クエリと候補を開いたまま、その選択肢をトグルします |
| Escape、Tab、ブラー、または外側の押下 | 下書きを終了します。単一モードではラベルを復元し、複数モードではクエリをクリアします |

Tab ストップになるのはクエリだけです。選択済みのチップは通常の
アプリケーションの Button で描画し、ユーザーによる削除には `remove_value(value, window, cx)` または
`clear(window, cx)` を呼び出します。これらの操作は変更後の選択を通知し、
フォーカスをクエリに戻し、無効なコントロールや IME の入力中の状態では拒否されます。
`set_disabled` はポップアップを閉じ、通常の入力をブロックします。`set_query` は
フォーカスされた下書きを開始します。マークされたテキストは候補のナビゲーションや確定より優先され、
Escape はまず入力中の状態を解除します。ヘッドレスのチェックでは、デスクトップの IME の
動作は確認できません。

`set_items(items, window, cx)` は Change イベントなしでソース項目を置き換えます。
現在の選択は安定した値に追従し、存在しなくなった値や新たに無効になった値は
削除されます。アクティブなクエリのテキスト、フォーカス、ネイティブの入力中の状態は保持されます。閉じた
単一選択では表示ラベルが更新されます。取得、読み込み、
リクエストの順序、エラーはアプリケーションが管理し、ネットワークコントローラーはインストールされません。

ネイティブのセマンティクスには、ComboBox のクエリ、expanded 状態、名前付きのグループ、
確定した選択値、および複数モードでの複数選択可能なリストボックスが含まれます。固定された
GPUI API では、input から兄弟のリストへの active-descendant の
関係を表現できません。自由形式の確定値は提供されません。結果は
Command のランク付けされた順序どおりのマッチングを使用します。
設定のサンプルは Dialog 内で単一のプリセットを保持します。カタログの
Selection ビューは、グループ化された複数のターゲット、チップの削除、ローカルの
ソース更新を、2 つ目の input や選択エンジンなしで示します。
