`DrawerState` は 1 つの `DialogState` を組み合わせます。`new(window, cx)` で構築するか、
`with_dialog` で設定済みの Dialog を取り込み、その State を 1 つの Drawer にマウントします。
`open`/`close`、初期フォーカス、封じ込め、Escape、バックドロップによる閉鎖、復帰先の
フォーカスは Dialog が引き続き管理します。State は `DialogEvent` を転送し、
通常の DialogClose コントロール用に `dialog()` を公開します。

既定では下辺に開きます。マウント前に `DrawerState` へ `.side(Placement::Left)` などを設定すると配置する辺を選べます。
どの辺でも `.handle(...)` で渡したハンドルを外側にドラッグして閉じられ、本体では通常どおりスクロールや編集ができます。
スナップ位置を指定しない場合、パネルの長さの 3 分の 1 以上ドラッグすると閉じ、それより短い距離なら元の位置に戻ります。

上辺または下辺に `.snap_points([0.5, 0.85])` を指定すると、ウィンドウの高さの半分から始まります。
ハンドルで高さを調整して離すと、閉じた位置を含め最も近い高さに移動します。
0 より大きく 1 以下の比率を昇順に指定します。ウィンドウをリサイズしてもこの比率は維持されます。
カタログのセッション確認画面では `snap_index()` と `set_snap_index(index, window, cx)` を使い、キーボードでも高さを変更できます。
ウィンドウが非アクティブになるとドラッグは取り消され、次に開くと直前のスナップ位置に戻ります。
