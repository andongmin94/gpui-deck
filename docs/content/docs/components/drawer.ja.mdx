title: Drawer
description: "Dialog のライフサイクルに加え、専用のハンドルによる下方向ドラッグでの閉鎖に対応します。"
---

`DrawerState` は 1 つの `DialogState` を組み合わせます。`new(window, cx)` で構築するか、
`with_dialog` で設定済みの Dialog を取り込み、その State を 1 つの Drawer にマウントします。
`open`/`close`、初期フォーカス、封じ込め、Escape、バックドロップによる閉鎖、復帰先の
フォーカスは Dialog が引き続き管理します。State は `DialogEvent` を転送し、
通常の DialogClose コントロール用に `dialog()` を公開します。

`Drawer::new(id, &state)` は、ビューポートに制限されたモーダルサーフェスを下部に配置します。
`.handle(...)`、任意の `.backdrop(...)`、スタイルを付けた本体とアクションを指定してください。
専用のハンドルを押したときだけ下方向のドラッグが始まり、本体内でのスクロールや編集では始まりません。
変位のしきい値を超えてからリリースすると Dialog を通じて閉じ、それより短い、またはキャンセルされたドラッグでは
サーフェスが静止位置に戻ります。ウィンドウが非アクティブになるとアクティブなドラッグはキャンセルされます。この契約には
静止位置が 1 つあり、慣性の物理演算やスナップポイントの設定はありません。
