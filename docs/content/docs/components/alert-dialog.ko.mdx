`AlertDialog::new(&dialog_state)`는 짧은 결정을 위해 기존 Dialog 호스트를 조합합니다.
동일하게 유지되는 `DialogState`, `DialogBackdrop`, `DialogPopup`,
`DialogTitle`, `DialogDescription`, `DialogClose` 부품을 사용하며, 별도의
경고 상태나 중복된 모달 수명 주기는 없습니다. 닫혀 있는 동안에도 호스트를 마운트해 둡니다.

호스트에 `accessibility_label`과 `accessibility_description`을 지정하고,
배경과 팝업을 제공합니다. 래퍼는 네이티브 역할을 AlertDialog로 고정하고
배경을 눌러 닫히지 않도록 막습니다. Escape는 여전히 Dialog의 기존 닫기 경로로
취소합니다. Tab 가두기와 포커스 복귀 역시 Dialog와 Root가 맡습니다.

취소 버튼용으로 안정적인 포커스 핸들을 만들고
`DialogState::new(cx).with_initial_focus(&cancel_focus)`에 전달합니다. 같은 핸들을
`DialogClose::trigger`가 제공하는 Button에도 적용합니다. 확인 버튼은 일반
Button이며, 애플리케이션 콜백이 액션을 수행하고 상태를 닫습니다.
대화 상자가 닫힌 것만으로는 확인을 뜻하지 않습니다. 확인 액션을 일반적인
`DialogEvent::Closed` 알림에 연결하지 마십시오.

예제의 Reset preview 메뉴 명령이 이 호스트를 엽니다. 처음에는 Cancel이 포커스를
가지며 현재 미리보기를 유지합니다. 명시적인 Reset preview 버튼만이 알려진 진행률
40%를 복원한 다음 포커스를 메뉴 트리거로 되돌립니다.
