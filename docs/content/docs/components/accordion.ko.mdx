`AccordionState`는 고정되고 순서가 있는 `AccordionItem::new(value,
label)` 항목 컬렉션을 소유합니다. 값은 고유해야 합니다. 초기 상태는 모두 접힌 상태이며,
`.default_open([value])`는 활성화된 항목 하나를 엽니다. 여러 패널을 동시에 열려면
`.multiple(true).default_open(["general", "details"])`를 사용합니다. 기본값은
활성화된 항목을 가리켜야 합니다. 단일 열림 모드에서 서로 다른 기본값을 둘 이상 지정하면
설정 오류이며 패닉이 발생합니다. 사용할 수 없는 항목은 `.disabled(true)`로 표시합니다.

헤더와 패널을 `Accordion::new(id, &state)`로 감싸 렌더링하고, 각
`AccordionHeader::new(&state, index)`를 `AccordionPanel::new(&state, index)`와
컬렉션 순서대로 짝지어 둡니다. 각 쌍은 일반 GPUI 컨테이너로 배치할 수 있습니다. 루트는
포커스 범위와 키보드 처리를 제공하지만 레이아웃이나 모양은 정하지 않습니다.

헤더는 네이티브 제목과 버튼을 포함합니다. 헤더의 자식과 스타일은 버튼에 적용되며,
`.heading_level(level)`로 제목 수준을 기본값 3에서 바꿀 수 있습니다.
헤더 안에는 비대화형 콘텐츠만 둡니다. 표시기는 애플리케이션이 그리며,
`is_open(index)`로 열린 헤더와 닫힌 헤더를 구분합니다.

| 헤더에서의 입력 | 동작 |
| --- | --- |
| Click / Enter / Space | 이 패널을 토글합니다. 단일 열림 모드에서는 이전 패널도 닫습니다 |
| Up / Down | 이전 / 다음 활성화된 헤더로 포커스를 옮기며, 양 끝에서 순환합니다 |
| Home / End | 첫 번째 / 마지막 활성화된 헤더로 포커스를 옮깁니다 |
| Tab / Shift-Tab | 활성화된 헤더와 열린 콘텐츠를 일반 문서 순서대로 따라갑니다 |

화살표 내비게이션은 패널을 펼치지 않습니다. 활성화된 모든 헤더는 일반 Tab
스톱입니다. 내비게이션 액션은 헤더 자체에 포커스가 있을 때만 적용되므로, 패널 안의
Input은 자신의 Home/End와 화살표 동작을 그대로 유지합니다. 비활성화된 헤더는
활성화되지 않으며 키보드 포커스 이동에도 참여하지 않습니다.

상태 메서드에는 `items`, `is_open`, `open_values`, `trigger_focus_handle`,
`panel_focus_handle`, `toggle(index, window, cx)`, `close(window, cx)`가 있습니다.
`AccordionEvent::Change(values)`를 구독하면 원래 항목 순서대로 열린 값을 받습니다.
빈 벡터는 모든 패널이 닫혔다는 뜻입니다. `close`는 열린 패널을 모두 닫습니다.
변화가 없는 요청은 이벤트를 다시 내보내지 않습니다. 소비자 화면을 다시 그리려면 상태를 관찰합니다.
카탈로그의 Navigation 도움말은 `.multiple(true)`로 독립적인 두 답변을 마운트하므로,
명령 설명을 열어도 정렬 답변이 유지됩니다. 세션 Help는 기본 단일 열림 계약을 유지합니다.

패널을 닫으면 그 레이아웃, 포커스 스톱, 접근성 노드가 제거됩니다. 다시 마운트되어도
유지되어야 하는 폼 값과 자식 엔티티는 애플리케이션 뷰에 둡니다. 패널은 기본적으로
자체 Tab 스톱이 없는 이름 있는 영역입니다. 정적 콘텐츠 자체가 포커스를 받아야 한다면
`.tab_stop(true)`를 사용합니다.

프로그래밍 방식의 변경이 키보드 포커스를 가진 패널을 닫으면, 포커스는 남아 있는
해당 헤더로 이동하거나, 섹션을 전환하는 경우 새로 열린 헤더로 이동합니다. 변경은
관련 없는 컨트롤의 포커스를 빼앗지 않습니다. 패널을 제거하기 전에 포커스를 옮기면
중첩된 Popover도 닫기 수명 주기를 마칠 수 있습니다. Accordion 호스트 전체를 제거하는
경우에는 애플리케이션이 남아 있는 컨트롤에 포커스를 주어야 합니다.

라이브러리는 제목 수준, 버튼 역할, 펼침/비활성화 상태, 이름 있는 Region을 내보냅니다.
버튼과 패널 사이의 명시적인 네이티브 controls/labelled-by 관계는 내보내지 않습니다.
고정된 GPUI API가 필요한 형제 노드 ID를 노출하지 않기 때문입니다.
