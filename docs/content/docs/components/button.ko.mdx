`Button`은 다른 컨트롤들이 기반으로 삼는 활성화 기본 요소입니다. 포인터와
Enter/Space 활성화, 포커스, 비활성화 상태, 네이티브 Button 역할을 소유합니다.
내용, 간격, 모양, 상태별 스타일은 애플리케이션이 맡습니다.

```rust
Button::new("save")
    .accessibility_label("Save session")
    .px_3()
    .py_2()
    .rounded(px(6.))
    .bg(palette.accent)
    .text_color(palette.accent_foreground)
    .focus_visible(|style| style.border_color(palette.ring))
    .styles(|styles| styles.disabled(|style| style.opacity(0.5)))
    .on_click(|_, window, cx| {
        // The application decides what activation does.
    })
    .child("Save")
```

## 활성화와 포커스

클릭, Enter, Space는 버튼을 한 번 활성화합니다. `.disabled(true)`는 활성화를
무시하고 Tab 스톱을 제거합니다. 포커스를 가진 상태에서 비활성화된 버튼은 포커스가
떠날 때까지 포커스 바인딩을 유지하므로 Tab으로 어느 방향으로든 계속 이동할 수 있습니다.
`.track_focus(&handle)`는 애플리케이션이 소유하는 포커스 핸들을 사용합니다. 예를 들어
대화 상자가 닫힌 뒤 포커스를 복원할 때 씁니다. `.tab_index(...)`와 `.tab_stop(...)`는
이동 순서를 조정합니다.

## 접근성

아이콘만 있는 버튼처럼 자식이 일반 텍스트가 아니면 언제나
`.accessibility_label(...)`로 버튼에 이름을 붙입니다. `.selected(true)`는 선택된
스타일만 적용합니다. `.current(true)`는 내비게이션 항목에 `aria-current="page"`를
별도로 노출하므로, 선택된 모양이 곧 현재 페이지를 뜻하지는 않습니다.

Toggle, Collapsible과 Tooltip 트리거, CarouselControl, 메뉴 트리거는 Button을
조합하므로 이 활성화 및 포커스 계약을 공유합니다.
