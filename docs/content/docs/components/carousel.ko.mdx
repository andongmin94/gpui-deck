`CarouselState::new(labels, cx)`는 고정되고 순서가 있는 컬렉션과 선택된(선두)
슬라이드를 유지합니다. 선택은 기본적으로 경계에서 멈추며, `.looping(true)`는 순환을 허용합니다.
`.slides_per_view(n)` 또는 `set_slides_per_view(n, window, cx)`는 shadcn의 비율 기반
항목 너비처럼 연속된 슬라이드 `n`개를 보여 줍니다. 각 단계는 슬라이드 하나씩 이동하고
마지막 화면도 꽉 찬 상태로 유지되므로, 선두 위치는 `snap_count()`개가 존재하며
`visible_range()`는 마운트된 슬라이드를 가리킵니다. 순환 모드에서는 마지막 꽉 찬 화면과
첫 화면 사이를 오갑니다. `Carousel::new(id, &state, label)`은 이름이 있는 포커스 가능
영역을 제공하고, `CarouselSlide::new(&state, index)`는 현재 화면에 있는 슬라이드만
마운트합니다. 슬라이드 데이터는 애플리케이션이 유지하며, 미디어, 슬라이드 너비(예:
한 행에 같은 `flex_1` 슬라이드), 콘텐츠, 표시기 화면 표현을 제공합니다.
`CarouselControl::previous/next`는 경계에서의 비활성화 동작과 함께 Button을 조합합니다.

가로 영역 자체에 포커스가 있을 때는 Left/Right가, 세로 영역에서는 Up/Down이 동작하며,
Home/End는 첫 번째와 마지막 화면을 선택합니다. 슬라이드 하위 요소는 자신의 키를
유지합니다. 축과 방향은 `Carousel`에 설정하며, 모든 슬라이드가 스와이프에 같은 상태를
사용합니다. 방향은 기본적으로 상속됩니다. 포인터를 40 논리 픽셀만큼 끌면 제스처당 한 번
스냅되며, 한 번 움직인 직후 바로 놓는 경우도 포함됩니다. 화면을 줄이는 경우를 포함해
슬라이드가 화면 밖으로 나가면, 그 안에 있던 포커스는 마운트 해제 전에 캐러셀 범위로
돌아갑니다. 계속 보이는 슬라이드와 외부 이전/다음 컨트롤의 포커스는 유지됩니다.
관성, 애니메이션 이동, 스냅 사이의 자유 스크롤은 없습니다.

`set_autoplay(Some(interval), window, cx)`는 간격마다 슬라이드 하나씩 진행하며
마지막 화면에서 첫 화면으로 순환합니다. `None`과 `is_autoplaying()`으로 제어하고
상태를 확인합니다. 포인터가 캐러셀 위에 있거나, 포커스가 안에 있거나, 창이 비활성이거나,
동작 줄이기가 켜져 있으면 회전이 일시 정지됩니다. 또한 Embla의 기본 자동 재생 플러그인처럼
키보드, 스와이프, `CarouselControl` 내비게이션이 회전을 멈춥니다. 페이지 표시의
`select` 같은 애플리케이션 호출은 회전을 멈추지 않습니다. 카탈로그의 "Play slideshow"처럼
보이는 재생/일시 정지 Button을 렌더링해 사용자가 회전을 멈출 수 있게 합니다(WCAG 2.2.2).
