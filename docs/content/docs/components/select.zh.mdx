title: Select
description: "支持更新选项的单选、带缓冲的输入定位、Home/End 与方向键导航、禁用选项、提交和焦点。"

打开展示时区的列表，按 Home、End、方向键或输入城市名的前几个字母，
列表会滚动到高亮选项。按 Enter 确认选择，也可以用滚轮浏览其他选项。
较短的列表按内容确定高度；使用 `Select::list_max_height(px(144.))`
可以在窗口允许的范围内设置一个更小的高度上限。

点击 **Show Asia only** 可将时区列表缩小到亚洲。已选的首尔会保留，已选的亚洲以外城市则会被清除。原生录制示例使用同一 API，在选择 Presentation 预设时启用激光笔工具。

`SelectState::new(items, cx)` 持有一组有序的唯一值、一个
已提交的值以及一个独立的弹出层打开状态光标。已禁用的选项会被跳过。
观察该状态以进行呈现，并订阅 `SelectEvent::Change` 以获知
用户提交的变更。`set_selected_value(Some(value), window, cx)` 设置一个
已启用的值；`None` 清除选择。被接受的更新会关闭弹出层，且不触发用户
事件，并使用其正常的焦点恢复。未知/已禁用的值返回 false，
且不会改变值、待定的光标或弹出层。当
整个控件被禁用时，应用更新仍然可用。

`set_items(items, window, cx)` 按唯一值保留已选项和高亮项。列表打开时会保留键盘焦点。如果高亮项被移除或禁用，光标将移至仍可用的已选项或第一个可用选项。所有选项均不可用时，列表会关闭。更新列表不会触发 `SelectEvent::Change`。

| 输入 | 结果 |
| --- | --- |
| Enter / Space | 打开弹出层，或提交其高亮的选项 |
| 上 / 下 | 打开并在已启用的选项之间移动 |
| 打开时的 Home / End | 高亮第一个 / 最后一个已启用的选项，但不提交 |
| 可打印字符 | 关闭时提交匹配的选项；打开时高亮该选项 |
| Escape | 放弃待定的选择，关闭并恢复触发器的焦点 |

输入定位匹配不区分大小写的标签前缀，并在一秒后重置。
重复的字母会在匹配的选项之间循环。带修饰键的快捷键、原生的
字符优先事件以及来自后代编辑器的按键不会触发搜索。
打开/关闭会清除前缀。这是一个不可编辑的 select；如需
可见的原生文本查询、分组结果或多选，请使用 Combobox。
