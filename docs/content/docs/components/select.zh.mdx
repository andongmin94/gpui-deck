`SelectState::new(items, cx)` 持有一组固定有序的唯一值、一个
已提交的值以及一个独立的弹出层打开状态光标。已禁用的选项会被跳过。
观察该状态以进行呈现，并订阅 `SelectEvent::Change` 以获知
用户提交的变更。`set_selected_value(Some(value), window, cx)` 设置一个
已启用的值；`None` 清除选择。被接受的更新会关闭弹出层，且不触发用户
事件，并使用其正常的焦点恢复。未知/已禁用的值返回 false，
且不会改变值、待定的光标或弹出层。当
整个控件被禁用时，应用更新仍然可用。

| 输入 | 结果 |
| --- | --- |
| Enter / Space | 打开弹出层，或提交其高亮的选项 |
| 上 / 下 | 打开并在已启用的选项之间移动 |
| 打开时的 Home / End | 高亮第一个 / 最后一个已启用的选项，但不提交 |
| 可打印字符 | 关闭时提交匹配的选项；打开时高亮该选项 |
| Escape | 放弃待定的选择，关闭并恢复触发器的焦点 |

输入定位匹配不区分大小写的标签前缀，并在一秒后重置。
重复的字母会在匹配的选项之间循环。带修饰键的快捷键、原生的
字符优先事件以及来自后代编辑器的按键不会触发搜索。
打开/关闭会清除前缀。这是一个不可编辑的 select；如需
可见的原生文本查询、分组结果或多选，请使用 Combobox。
