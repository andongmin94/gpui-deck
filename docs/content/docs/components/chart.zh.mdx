`ChartState` 接受类别标签和 `ChartSeries` 的值。每个系列在每个类别上都有一个
有限的值。保留的状态提供可见系列、被检查的
类别、精确值描述，以及包含零的带符号数值范围。
隐藏所有系列或使用全为零的数据时，会得到可用的 `0..1` 范围。该范围
会保留到可见性或布局发生变化；对某个点进行归一化不会
重新扫描数据集。

`ChartLayout` 选择同一份数据如何共享绘图区，`set_layout` 会保留
可见性和检查状态：

- `Grouped`（默认）在均匀分布的类别带上并排放置各系列。
- `Stacked` 分别从零开始堆叠正值和负值。其范围
  涵盖每个类别的可见总和，`stack_span(series, category)` 给出某个
  可见分段的起止值。
- `Pie` 为每个类别提供一个扇区，其大小由该类别可见系列的非负
  总和决定。`pie_slices` 返回起止的圈数；总和为零或负数时，
  扇区为空。
- `Radar` 将类别放在均匀分布的轴线上（`radar_turn`），半径
  的归一化方式与 Grouped 相同。

径向的圈数从顶部起顺时针计算，在 RTL 中则镜像为逆时针。
`Chart` 提供一个带名称的绘图焦点区域：在所有布局中，左/右/Home/End 用于检查
各个类别。指针移动时，Grouped/Stacked 按水平带检查，
Pie/Radar 则按最大的居中圆内的角度检查；
指针位于该圆之外或不在任何扇区上时，会保持当前的检查状态。它
会触发检查/可见性事件，而不规定颜色或绘制路径。

可复制的 `examples/recipes/chart.rs` 基于这种行为，使用 GPUI canvas 构建了
折线图、分组柱状图、面积图、堆叠柱状/面积图、饼图、环形图和雷达图，
并带有坐标轴或轴线标签、饼图类别图例、基于 Toggle 的系列图例、精确值
读数，以及包含同一完整数据集的普通 Table。`ChartKind::layout`
给出每种类型所绘制的状态布局；目录中的 Media and data 视图在切换类型或方向时
会同时设置二者，并保留图例/检查状态。绘图
几何、调色板和数值格式属于使用方。这份分类数据
约定不提供时间/对数刻度、按扇区的图例选择、缩放、
流式数据接入，也不提供单独的渲染引擎。

复制配方时，向 `ChartRecipe::new` 传入图表的无障碍名称、完整数据表的名称和类别列标题。
默认刻度会保留小数。使用 `format_value` 指定单位后，坐标轴刻度、当前读数、原生无障碍读数和表格单元格都会采用相同的格式。

```rust
ChartRecipe::new("latency", &state, ChartKind::Line, Direction::Ltr,
    "请求延迟", "全部延迟测量值", "路径")
    .format_value(|value| format!("{value} ms"))
```
