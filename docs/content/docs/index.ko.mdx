라이브러리는 컨트롤 동작, 상태, 포커스, 접근성 시맨틱을 소유합니다.
애플리케이션은 컴포넌트 소스, 레이아웃, 색상, 타이포그래피, 에셋을 소유합니다.
헤드리스는 컨트롤 동작을 애플리케이션이 소유하는 화면 표현과 분리합니다. 예제는
네이티브 GPUI 창을 렌더링하며, 이 사이트의 미리보기는 GPUI의 웹 백엔드를 통해
같은 컴포넌트를 브라우저에서 실행합니다.

GPUI Design은 현재 42개의 공개 라이브러리 패밀리와 23개의 복사 가능한
화면 표현 레시피를 포함합니다. shadcn/ui 카탈로그의 모든 항목은 구현된
범위나 플랫폼 매핑을 가지며, 그 한계는
[커버리지와 현황](./coverage.mdx)에 기록되어 있습니다.
