Install [Rust with rustup](https://rustup.rs/). The repository selects **Rust
1.99.1**, including rustfmt and Clippy, through `rust-toolchain.toml`.

On **Windows**, use the MSVC toolchain with the Visual Studio C++ build tools and
a Windows SDK. On **macOS**, install Xcode Command Line Tools with
`xcode-select --install`. On **Ubuntu 24.04**, install the native build dependencies:

```sh
sudo apt-get update
sudo apt-get install --no-install-recommends -y \
  build-essential pkg-config \
  libfontconfig1-dev libfreetype6-dev libwayland-dev \
  libxkbcommon-x11-dev libx11-xcb-dev libvulkan1
```

## Install in a Rust application

Add GPUI Deck and the matching GPUI crates to your application's `Cargo.toml`.

```toml
[dependencies]
gpui-deck = "0.0.1"
gpui = { package = "gpui-pre", version = "=0.3.12" }
gpui_platform = { package = "gpui-pre-platform", version = "=0.3.12", features = ["font-kit", "x11", "wayland", "runtime_shaders"] }

[features]
test-support = ["gpui-deck/test-support"]
```

The feature declaration supports the test guards in copied recipe source;
enable it when running those GPUI tests. Use the repository's pinned Rust toolchain and native prerequisites above. Copy
the desired presentation recipes into the application using their
[dependency and token instructions](/en/docs/guides/recipes/).

The GPUI snapshot family is pinned to **`=0.3.12`**. Update those pins and
`Cargo.lock` together when changing the rendering dependency.

From your application root, install the CLI from crates.io and copy the recipes into `src/ui`.

```sh
cargo install gpui-deck-cli --version 0.0.3 --locked
gpui-deck list
gpui-deck add data-table avatar --to src/ui
```

To install a custom style, choose your settings in [Create](/en/create) and copy the command under **Get code**. It installs the selected style, fonts and icons with the same CLI.

[Install and share blocks](/en/docs/guides/blocks/)

Declare `mod ui;` in the consumer. The tool preserves edits to previously installed
recipe and palette files; modified generated module declarations or new-file
conflicts stop before writing. It leaves Cargo dependencies to the consumer.
See the [source-copy guide](/en/docs/guides/recipes/).

## Run the native examples

Clone the repository and run the examples from a native desktop session.

```sh
git clone https://github.com/andongmin94/gpui-deck.git
cd gpui-deck
cargo run -p gpui-deck --example two_styles --locked -- compact
cargo run -p gpui-deck --example two_styles --locked -- settings
cargo run -p gpui-deck --example catalogue --locked
cargo run -p gpui-deck --example starter --locked
```

`compact` is the default when no appearance argument is supplied. Both commands
run the same session-settings interaction with application-owned styling.

Start with [`starter.rs`](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/starter.rs) for a small complete
application. It uses only public APIs: `init`, `Root`, a retained `InputState`,
`Field`, and `Button`. The application keeps its observation and event subscriptions,
owns the colors and layout, and handles both Enter and button activation.
For a new app, copy `starter.rs` to `src/main.rs` and the entire
[`crates/base/examples/assets/fonts`](https://github.com/andongmin94/gpui-deck/tree/main/crates/base/examples/assets/fonts) directory to `src/assets/fonts`, including the font files and their license. The starter registers Pretendard when it launches.

The catalogue's Selection section demonstrates range/multiple dates, grouped
recording targets, removable selected chips and replaceable local option data.
