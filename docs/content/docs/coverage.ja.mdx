参照カタログは **2026-11-21** に確認しました。
[shadcn/ui All Components](https://ui.shadcn.com/docs/components)。
そのメインカタログには **66 のエントリー** があり、以下にそれぞれ 1 回ずつ記載しています。別枠の
AI Elements カタログはこの比較の対象外ですが、メインカタログにすでに含まれている会話系コンポーネントは対象に含めています。

GPUI Deck は **42 の公開ライブラリファミリーと、コピーして使える 23 の
プレゼンテーション/構成レシピ** をドキュメント化しており、**65 の個別の実装** を提供します。
残る 1 つのカタログエントリーである Native Select は、GPUI では **Select にマッピング** されます。
**66 の参照エントリーすべてに、実装済みのスコープまたはプラットフォームへのマッピングがあります**。
未割り当てのもの、Pending のものはありません。

これはカタログのカバレッジであり、shadcn/ui の機能の完全な同等性ではありません。各契約には明示的な制限があり、HTML 固有のマッピングはブラウザーのコントロールやオペレーティングシステムのピッカーを実装するものではありません。これらの数は、パフォーマンス、アクセシビリティ適合性、ネイティブデスクトップでの検証の完了度を測るものではありません。

目標は、アプリケーション構築の幅において同等であることです。共有される動作はライブラリに置き、再利用可能なプレゼンテーションと画面の構成は、そのソースをアプリケーションが所有します。以下のグループは、shadcn の内部アーキテクチャではなく、私たちの実装上の責務を説明するものです。`two_styles` と `catalogue` のネイティブサンプルは、再利用可能な[プレゼンテーションレシピ](./guides/recipes.mdx)を使用します。レシピのソースはこのリポジトリで配布され、ローカルのソース CLI がレシピ、依存関係、トークン、ライセンスをコンシューマーが所有するモジュールにインストールします。リモートレジストリは提供されません。

## ステータスの意味

- **Available:** 公開ファミリーとコンシューマーのサンプルが、記載したスコープをカバーしています。
- **Recipe:** 再利用可能なアプリケーションソースと動作するコンシューマーのサンプルが、記載したプレゼンテーションをカバーしています。レシピはライブラリの公開エクスポートの外にあります。
- **Mapped:** 明示的な GPUI のプラットフォーム相当機能が、ネイティブアプリケーションの必要を満たします。ブラウザー専用の契約は、エイリアスの背後に隠さず、ドキュメント化されています。

## 動作とセマンティクスの基盤

これらのコンポーネントは、インタラクション、状態、フォーカス、または再利用可能なセマンティクスの契約を担います。
外観はアプリケーションが所有します。実装済みの API の詳細は、
[フォームガイド](./guides/forms.mdx)、
[ナビゲーションとオーバーレイのガイド](./guides/navigation-overlays.mdx)、
[レイアウトとデータのガイド](./guides/layout-data.mdx)で説明しています。

## プレゼンテーションと構成のレシピ

これらのエントリーが主に必要とするのは、一貫した視覚的デフォルトと適切なセマンティクスを備えた、再利用可能なソースの構成です。
既存の GPUI のレイアウトとコントロールが役割を果たすべきであり、視覚的な名前ごとに新しい状態コントローラーを追加する必要はありません。
公開されているレシピは `crates/base/examples/recipes` にあり、視覚的なスタイリングはコンシューマーに置き、ネイティブの two-style サンプルに組み込まれています。

## 完了基準と現在の作業

目標は、ネイティブ GPUI 上で、動作、アクセシビリティ、視覚的デフォルト、ソース配布にわたって shadcn/ui 水準の使いやすさを実現することです。66 エントリーのカタログが数えるのは、スコープのカバレッジだけです。
それは完了率でも、リリース準備が整っているという主張でもありません。上記の `Available`、`Recipe`、`Mapped` は、同等性が完了していることを意味しません。

作業は、別の進捗レポートを作らず、ここと Git で管理します。機能は、ドキュメント化されたコンシューマーの契約が実装され、ネイティブのサンプルで動作が確認され、既存の適切なテストレイヤーでカバーされ、正確にドキュメント化されたときに完了となります。プラットフォームでの観察は、自動チェックとは別に記録します。

### Windows で実機確認する手順

リポジトリのルートで PowerShell を開き、確認したいサンプルのコマンドを実行します。次のサンプルを起動する前に、開いているサンプルのウィンドウを閉じてください。

```powershell
cargo run -p gpui-deck --example starter --locked
cargo run -p gpui-deck --example catalogue --locked
cargo run -p gpui-deck --example two_styles --locked -- settings
```

`catalogue` では Navigation のほか、OTP、Drawer、Toast、メディア、チャート、会話、アンケートのサンプルも確認できます。

| 確認項目 | 操作 | 期待する結果 |
| --- | --- | --- |
| ハングルの組み立てとフォント · `starter` | タスクバーで韓国語 IME を `가` モードにします。**Your name** に `한글` と入力し、英数入力に切り替え、半角スペースと `ABC 123` を続けて入力して **Say hello** を押します。 | 子音と母音を組み合わせる途中で文字が消えたり重複したりせず、結果に `Hello, 한글 ABC 123!` と表示されます。入力欄と結果の両方で文字が欠けず、四角い代替記号も出ません。 |

## 参照上の違い

[shadcn の紹介ページ](https://ui.shadcn.com/docs)は、ソースの所有、
構成、配布、視覚的デフォルトを説明しています。同等の幅には、
ヘッドレスな動作だけでなく、コンシューマー向けのそれらのレシピも含まれます。

現在の [Combobox](https://ui.shadcn.com/docs/components/base/combobox)
のドキュメントは、編集可能なオートコンプリートと追加の選択バリエーションを扱っています。
ここでの実装は、グループ化された単一/複数選択とアイテムの
置き換えを提供します。チップのプレゼンテーションと非同期リクエストの
所有はアプリケーションに残ります。これらの機能は、コンポーネントを増やすのではなく、同じファミリーを深めるものです。
[Command](https://ui.shadcn.com/docs/components/base/command) は、2 つ目の独立した
コマンドエンジンを必要とせず、ダイアログとの合成を含んでいます。

[Date Picker](https://ui.shadcn.com/docs/components/base/date-picker) は、
カレンダーとポップアップの部品から構成されます。
[Data Table](https://ui.shadcn.com/docs/components/base/data-table) は、
共有された基盤の上にアプリケーション固有のテーブルを構築するためのガイドです。
[Native Select](https://ui.shadcn.com/docs/components/base/native-select) は、
ブラウザーの HTML コントロールを明示的にラップしているため、そのプラットフォームの契約には適応が必要です。
