---
title: はじめに
description: Rust と GPUI のための、ソースを自分で所有するヘッドレス UI 基盤です。
---

ライブラリはコントロールの動作、状態、フォーカス、アクセシビリティのセマンティクスを担います。
アプリケーションは、コンポーネントのソース、レイアウト、色、タイポグラフィ、アセットを所有します。
ヘッドレスとは、コントロールの動作をアプリケーションが所有するプレゼンテーションから切り離すことです。
サンプルはネイティブの GPUI ウィンドウで描画され、このサイトのプレビューは GPUI の Web バックエンドを通じて、同じコンポーネントをブラウザー上で実行しています。

GPUI Design には現在、42 の公開ライブラリファミリーと、コピーして使える 23 のプレゼンテーションレシピが含まれています。
shadcn/ui カタログのすべてのエントリーには、実装済みのスコープまたはプラットフォームへのマッピングがあり、その制限は
[カバレッジとステータス](./coverage.mdx)に記録されています。
