## Install the billing dashboard

[Preview the billing dashboard](/en/blocks/billing-dashboard/) to try the chart and invoice table or read the Rust files before installation.

Start with a Rust application and the Cargo dependencies in the [installation guide](/en/docs/installation/). Run these commands at the application root with `curl` on your PATH.

```sh
cargo install gpui-deck-cli --version 0.0.4 --locked
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/blocks/billing-dashboard/block.json
```

The default destination is `src/ui`. The block’s Rust module and team palette land in `src/ui/billing_dashboard/`. Its chart and data table share that palette. The CLI also installs the table’s input group, pagination and empty state. Use `--to` to choose a different UI module.

Put this in `src/main.rs`, then run `cargo build` or `cargo run`.

```rust
mod ui;

use gpui::AppContext as _;
use ui::billing_dashboard::BillingDashboard as Screen;

fn main() {
    gpui_platform::application().run(|cx| {
        gpui_deck::init(cx);
        cx.open_window(Default::default(), |window, cx| {
            let screen = cx.new(|cx| Screen::new(window, cx));
            cx.new(|cx| gpui_deck::Root::new(screen, window, cx))
        })
        .expect("open block window");
        cx.activate(true);
    });
}
```

## Publish your team's block [#publish]

Commit a `block.json` file and the source files it lists to a public GitHub repository. The [billing dashboard source](https://github.com/andongmin94/gpui-deck/tree/main/blocks/billing-dashboard) is a complete example.

```json
{
  "version": 1,
  "name": "billing-dashboard",
  "recipes": ["chart", "data-table"],
  "files": [
    { "source": "dashboard.rs", "target": "mod.rs" },
    { "source": "palette.rs", "target": "palette.rs" },
    { "source": "components/panel.rs", "target": "components/panel.rs" }
  ]
}
```

`name` determines the Rust module directory (`billing-dashboard` becomes `billing_dashboard`). `recipes` lists the bundled recipes the block imports. Under `files`, each `source` is relative to the manifest and each `target` is relative to the installed block module. Include a `mod.rs` target for the entry point. Add your team's own palette, components and assets to this list.

Use a lowercase, hyphen-separated name. Keep relative file paths portable with letters, numbers, underscores, hyphens and dots. For example, a `brand/button.rs` source can be installed as `components/button.rs`.

Share the GitHub file URL for the manifest, or its `raw.githubusercontent.com` URL. Link to a commit to share an exact revision. Users can edit the installed Rust files in their app. Repeating the same URL keeps their edits. Review the author's source before building.

`gpui-deck diff --to src/ui` compares the bundled recipes and their generated scaffolding. Use your project's Git diff for the team's block files.

## Share a collection

The [Neobrutal registry](https://github.com/andongmin94/gpui-deck/tree/main/registries/neobrutal) shows how to share a visual style across items. Put one manifest per installable item next to the Rust source in your team's public GitHub repository. The login manifest lists the same button, input and palette files used by the individual components. One login install therefore includes all three.

After a standalone install, render a button with `ui::neobrutal_button::press_button("save", "Save")` and attach your handler with `.on_click(...)`. For a field, create the input state once with `ui::neobrutal_input::editor` inside `cx.new(...)`, then pass that state to `ui::neobrutal_input::field` on each render.

List your item manifests in a `registry.json` catalog so readers can browse the collection. Share the GitHub URL of an **item manifest** for `gpui-deck add`. To browse a working collection, open the [registry directory](/en/directory).

## Run an installed registry item [#registry]

After adding the [Cargo dependencies](/en/docs/installation), install an item from the directory. For example, install Select with the command below. In the window example above, remove the `Screen` import and replace the line that constructs `screen` with the Rust line below. Run `cargo run` to open the same interactive example as the website.

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/select.json
```

```rust
let screen = ui::neobrutal_select::preview(window, cx);
```

Use the component's function directly in your own view when you are ready to supply your own state and content.

## Use a registry theme

Install both items in the same UI directory. Pass the theme palette to a component when you render it. Use `palette(true)` for the dark palette.

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/button.json
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/theme-blue.json
```

```rust
let palette = ui::neobrutal_theme_blue::palette(false);
let save = ui::neobrutal_button::press_button_with_palette("save", "Save", palette);
```

To run the project dashboard with the same theme, install its template into the same app.

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/dashboard-template.json
```

In the window example above, replace the `use … as Screen;` import with the following one.

```rust
use ui::neobrutal_dashboard_template::Dashboard as Screen;
```

Inside `open_window`, replace the line that creates `screen` with these two lines, then run `cargo run`.

```rust
let palette = ui::neobrutal_theme_blue::palette(true);
let screen = cx.new(|cx| Screen::new(palette, window, cx));
```

## Use the Neumorphism collection

Open the [Neumorphism registry](/en/directory/neumorphism) for the live example and install command for every item. Install the button and Sage preset in the same application, then pass the palette when rendering the button. Use `palette(true)` for dark mode.

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neumorphism/button.json
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neumorphism/style-sage.json
```

```rust
let palette = ui::neumorphism_style_sage::palette(false);
let save = ui::neumorphism_button::press_button_with_palette("save", "Save", palette);
```
