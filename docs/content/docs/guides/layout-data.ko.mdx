Table, ScrollArea, Resizable은 재사용 가능한 구조와 네이티브 동작을 제공합니다. 데이터,
레이아웃 크기, 색상, 타이포그래피, 셀 콘텐츠는 애플리케이션이 소유합니다.
[두 스타일 예제](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/two_styles.rs)는 Schedule 탭에서
이들을 조합하고, 주변 폼에는 ScrollArea를 사용합니다.

## 스크롤 영역 안의 테이블

열이 뷰포트보다 넓어야 한다면 테이블의 너비나 최소 너비를 명시적으로 지정합니다.
네이티브 예제는 양방향 스크롤을 지원하는 ScrollArea 안에 합계 490픽셀인
고정 열 세 개를 사용합니다. 주변의 설정 폼은 세로로 스크롤됩니다.
중첩된 테이블은 폼의 날짜를 바꾸거나 관련 없는 형제 요소를 스크롤하지 않고
가로로 이동할 수 있습니다. 날짜 선택과 이름/프리셋 편집은 다른 컨트롤이 쓰는
같은 유지되는 상태에서 테이블을 갱신합니다.

## 검증 범위

집중 테스트는 열 정렬, 테이블 메타데이터, 상호작용하는 셀 자식,
네이티브 스크롤과 표시, 구분선 드래그/키보드 동작, 그리고
DatePicker에서 크기 조절 가능한 계획으로 이어지는 예제 흐름을 다룹니다. 기존
CI는 Linux, Windows, macOS에서 네이티브 예제도 빌드합니다. 자동화된 GPUI
이벤트/레이아웃 확인은 네이티브 시각, 스크린리더, 혼합 DPI,
성능 결과를 보장하지 않습니다.
