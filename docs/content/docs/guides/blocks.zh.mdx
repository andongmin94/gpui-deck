## 安装账单仪表盘

在[账单仪表盘预览](/zh/blocks/billing-dashboard/)中试用图表和账单表格，查看即将安装的 Rust 源码。

按[安装指南](/zh/docs/installation/)为 Rust 应用添加 Cargo 依赖。确保 `curl` 在 PATH 中可用，然后在应用根目录执行以下命令。

```sh
cargo install gpui-deck-cli --version 0.0.2 --locked
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/blocks/billing-dashboard/block.json
```

默认安装目录是 `src/ui`。仪表盘模块和团队配色位于 `src/ui/billing_dashboard/`。图表和账单表格使用同一套配色。CLI 还会安装表格依赖的输入组、分页和空状态配方。可通过 `--to` 指定其他 UI 模块目录。

将以下代码放入 `src/main.rs`，然后运行 `cargo build` 编译，或运行 `cargo run` 打开窗口。

```rust
mod ui;

use gpui::AppContext as _;
use ui::billing_dashboard::BillingDashboard as Screen;

fn main() {
    gpui_platform::application().run(|cx| {
        gpui_deck::init(cx);
        cx.open_window(Default::default(), |window, cx| {
            let screen = cx.new(|cx| Screen::new(window, cx));
            cx.new(|cx| gpui_deck::Root::new(screen, window, cx))
        })
        .expect("open block window");
        cx.activate(true);
    });
}
```

## 打开其他区块

从区块页面复制并运行安装命令，再将上例中的 `use ... as Screen` 替换为对应的导入语句。

| 区块 | 导入语句 |
| --- | --- |
| [登录](/zh/blocks/login) | `use ui::login::Login as Screen;` |
| [侧边栏设置](/zh/blocks/sidebar-settings) | `use ui::sidebar_settings::SidebarSettings as Screen;` |
| [Neobrutal 登录](/zh/directory/neobrutal) | `use ui::neobrutal_login::Login as Screen;` |

## 发布团队区块 [#publish]

将 `block.json` 及其中列出的源文件提交到公开的 GitHub 仓库。[账单仪表盘源码](https://github.com/andongmin94/gpui-deck/tree/main/blocks/billing-dashboard)提供了完整示例。

```json
{
  "version": 1,
  "name": "billing-dashboard",
  "recipes": ["chart", "data-table"],
  "files": [
    { "source": "dashboard.rs", "target": "mod.rs" },
    { "source": "palette.rs", "target": "palette.rs" },
    { "source": "components/panel.rs", "target": "components/panel.rs" }
  ]
}
```

`name` 决定 Rust 模块的目录名，例如 `billing-dashboard` 对应 `billing_dashboard`。在 `recipes` 中列出区块引用的内置配方。`files` 中的 `source` 相对于清单文件，`target` 相对于安装后的区块目录。入口文件的 `target` 为 `mod.rs`。将团队自己的配色、组件和资源也添加到此列表。

区块名称以小写英文字母开头，各单词用连字符分隔。相对路径可使用英文字母、数字、下划线、连字符与点。例如，可以将 `brand/button.rs` 安装为 `components/button.rs`。

分享清单文件的 GitHub 网页 URL 或 `raw.githubusercontent.com` URL。要固定版本，请分享指向特定提交的链接。使用者可以直接编辑安装好的 Rust 源码，再次添加同一个 URL 会保留这些修改。构建前请检查作者的源码。

`gpui-deck diff --to src/ui` 可比较内置配方和生成的模块声明。团队区块源文件的修改可以用应用仓库的 Git diff 查看。

## 分享组件集合

可以参考 [Neobrutal 注册表](https://github.com/andongmin94/gpui-deck/tree/main/registries/neobrutal)，将 Rust 源文件和每个可安装项目的清单放在团队的公开 GitHub 仓库中。登录页的清单引用了与独立组件相同的按钮、输入框和调色板文件，安装一次即可获取完整界面。

单独安装按钮后，使用 `ui::neobrutal_button::press_button("save", "保存")` 渲染按钮，并通过 `.on_click(...)` 绑定操作。对于输入框，在 `cx.new(...)` 中通过 `ui::neobrutal_input::editor` 创建一次状态，然后在每次渲染时将该状态传给 `ui::neobrutal_input::field`。

在 `registry.json` 中列出各个项目的清单，供读者浏览。运行 `gpui-deck add` 时，传入要安装的**项目清单**的 GitHub 文件链接。[注册表目录](/zh/directory)中有可用的示例。

## 运行安装的注册表项目 [#registry]

添加 [Cargo 依赖](/zh/docs/installation) 后，从目录选择项目。例如，使用下面的命令安装 Select。删除上方窗口示例中的 `Screen` 导入，将创建 `screen` 的一行替换为下面的 Rust 代码。运行 `cargo run` 即可在原生窗口中使用与网站相同的交互示例。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/select.json
```

```rust
let screen = ui::neobrutal_select::preview(window, cx);
```

要接入自己的数据和行为，可以在视图中直接调用同一模块的组件函数。

## 使用注册表主题

将按钮和主题安装到同一个 UI 目录，渲染组件时传入主题调色板。深色模式使用 `palette(true)`。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/button.json
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/theme-blue.json
```

```rust
let palette = ui::neobrutal_theme_blue::palette(false);
let save = ui::neobrutal_button::press_button_with_palette("save", "保存", palette);
```

要在同一应用中给项目仪表盘使用蓝色主题，先安装仪表盘模板。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/dashboard-template.json
```

将上面窗口示例中的 `use … as Screen;` 替换为下面的导入语句。

```rust
use ui::neobrutal_dashboard_template::Dashboard as Screen;
```

在 `open_window` 中，用下面两行替换创建 `screen` 的语句，然后运行 `cargo run`。

```rust
let palette = ui::neobrutal_theme_blue::palette(true);
let screen = cx.new(|cx| Screen::new(palette, window, cx));
```

## 使用新拟态组件

在[新拟态注册表](/zh/directory/neumorphism)中可运行每个示例并复制安装命令。在同一应用中安装按钮和鼠尾草主题，渲染按钮时传入调色板。深色模式使用 `palette(true)`。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neumorphism/button.json
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neumorphism/style-sage.json
```

```rust
let palette = ui::neumorphism_style_sage::palette(false);
let save = ui::neumorphism_button::press_button_with_palette("save", "保存", palette);
```
