## 청구 대시보드 설치

[청구 대시보드 미리보기](/ko/blocks/billing-dashboard/)에서 차트와 청구서 표를 조작하고 설치할 Rust 소스를 확인할 수 있습니다.

Rust 앱에 [설치 가이드](/ko/docs/installation/)의 Cargo 의존성을 추가합니다. `curl`을 실행할 수 있는 환경에서 앱 루트로 이동해 다음 명령을 실행하세요.

```sh
cargo install gpui-deck-cli --version 0.0.2 --locked
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/blocks/billing-dashboard/block.json
```

기본 설치 경로는 `src/ui`입니다. 대시보드와 팀 팔레트는 `src/ui/billing_dashboard/`에 들어갑니다. 차트와 청구서 표는 같은 팔레트를 사용하며, 표에 필요한 입력 그룹·페이지 이동·빈 상태 레시피도 함께 설치됩니다. 다른 UI 모듈에 넣으려면 `--to`로 경로를 지정하세요.

다음 코드를 `src/main.rs`에 넣고 `cargo build`로 빌드하거나 `cargo run`으로 창을 여세요.

```rust
mod ui;

use gpui::AppContext as _;
use ui::billing_dashboard::BillingDashboard;

fn main() {
    gpui_platform::application().run(|cx| {
        gpui_deck::init(cx);
        cx.open_window(Default::default(), |window, cx| {
            let dashboard = cx.new(|cx| BillingDashboard::new(window, cx));
            cx.new(|cx| gpui_deck::Root::new(dashboard, window, cx))
        })
        .expect("open billing dashboard");
        cx.activate(true);
    });
}
```

## 우리 팀의 블록 공유

공개 GitHub 저장소에 `block.json`과 여기에 나열한 소스 파일을 커밋합니다. [청구 대시보드 소스](https://github.com/andongmin94/gpui-deck/tree/main/blocks/billing-dashboard)에서 실제 파일 구성을 볼 수 있습니다.

```json
{
  "version": 1,
  "name": "billing-dashboard",
  "recipes": ["chart", "data-table"],
  "files": [
    { "source": "dashboard.rs", "target": "mod.rs" },
    { "source": "palette.rs", "target": "palette.rs" },
    { "source": "components/panel.rs", "target": "components/panel.rs" }
  ]
}
```

`name`은 Rust 모듈 디렉터리 이름을 정합니다. 예를 들어 `billing-dashboard`는 `billing_dashboard`가 됩니다. `recipes`에는 블록이 가져올 기본 레시피를 적습니다. `files`의 `source`는 매니페스트 기준 경로이고, `target`은 설치할 블록 모듈 안의 경로입니다. 진입 파일의 `target`을 `mod.rs`로 정하고 팀 팔레트, 전용 컴포넌트, 에셋도 목록에 추가하세요.

블록 이름은 영문 소문자로 시작하고 단어는 하이픈으로 구분합니다. 상대 파일 경로에는 영문자·숫자·밑줄·하이픈·점을 사용할 수 있습니다. 예를 들어 `brand/button.rs`를 `components/button.rs`에 설치할 수 있습니다.

`block.json`을 연 GitHub 파일 URL이나 `raw.githubusercontent.com` URL을 공유하세요. 같은 버전을 재현하려면 특정 커밋을 가리키는 링크를 사용하세요. 설치한 사람은 Rust 파일을 직접 수정할 수 있고, 같은 URL을 다시 추가해도 수정 내용이 유지됩니다. 빌드 전에 작성자의 소스를 확인하세요.

`gpui-deck diff --to src/ui`는 기본 레시피와 생성된 모듈 선언을 비교합니다. 팀이 작성한 블록 파일의 변경 사항은 앱 저장소의 Git diff에서 확인하세요.
