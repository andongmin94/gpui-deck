## 청구 대시보드 설치

[청구 대시보드 미리보기](/ko/blocks/billing-dashboard/)에서 차트와 청구서 표를 조작하고 설치할 Rust 소스를 확인할 수 있습니다.

### 새 앱으로 실행 [#new-app]

<a href="/downloads/billing-dashboard.zip" download>청구 대시보드 프로젝트</a>를 다운로드해 압축을 풀고 `billing-dashboard` 폴더에서 터미널을 여세요. [운영체제별 빌드 도구](/ko/docs/installation/)를 준비한 뒤 실행합니다.

```sh
cargo run
```

### 기존 앱에 추가 [#existing-app]

Rust 앱에 [설치 가이드](/ko/docs/installation/)의 Cargo 의존성을 추가합니다. `curl`을 실행할 수 있는 환경에서 앱 루트로 이동해 다음 명령을 실행하세요.

```sh
cargo install gpui-deck-cli --version 0.0.4 --locked
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/blocks/billing-dashboard/block.json
```

기본 설치 경로는 `src/ui`입니다. 대시보드와 팀 팔레트는 `src/ui/billing_dashboard/`에 들어갑니다. 차트와 청구서 표는 같은 팔레트를 사용하며, 표에 필요한 입력 그룹·페이지 이동·빈 상태 레시피도 함께 설치됩니다. 다른 UI 모듈에 넣으려면 `--to`로 경로를 지정하세요.

`src/ui`를 처음 추가했다면 크레이트 루트에 `mod ui;`를 선언하세요. 기존 뷰의 생성자에서 `gpui::AppContext as _`를 가져와 대시보드를 한 번 생성합니다.

```rust
let billing = cx.new(|cx| crate::ui::billing_dashboard::BillingDashboard::new(window, cx));
```

반환값을 `gpui::Entity<crate::ui::billing_dashboard::BillingDashboard>` 타입의 `billing` 필드에 보관하세요. 기존 GPUI Deck 창에서 `.child(self.billing.clone())`으로 표시할 수 있습니다.

별도 청구 창을 열려면 아래 두 파일을 `src/`에 복사하고 크레이트 루트에 `mod screen;`과 `mod block_window;`를 선언하세요. 앱 시작 시 `gpui_deck::init(cx)` 다음에 `block_window::open(cx)`를 호출합니다.

<include lang="rust" meta='title="src/screen.rs"'>../../../../blocks/billing-dashboard/app/screen.rs</include>

<include lang="rust" meta='title="src/block_window.rs"'>../../../../blocks/starter/block_window.rs</include>

## 다른 블록 열기

새 앱은 프로젝트 ZIP으로 받을 수 있습니다. 기존 GPUI 앱에는 [기존 앱 설치 안내](#existing-app)에 따라 Cargo 의존성과 `mod ui;`를 준비한 뒤 원하는 화면을 추가하세요. 부모 뷰에서 `gpui::AppContext as _`를 가져오고 생성자에서 자식 뷰를 한 번 생성합니다.

### 로그인 [#login]

[미리보기](/ko/blocks/login) · <a href="/downloads/login.zip" download>프로젝트 다운로드 (.zip)</a>

ZIP을 풀고 `login` 폴더에서 `cargo run`을 실행하세요.

기존 앱에 붙이려면 앱 루트에서 아래 명령을 실행하세요.

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/blocks/login/block.json
```

```rust
let login = cx.new(|cx| crate::ui::login::Login::new(window, cx));
```

`login`을 `gpui::Entity<crate::ui::login::Login>` 필드에 보관하고 `.child(self.login.clone())`으로 표시하세요. 폼은 로컬에서 입력값을 검증합니다. 인증 서비스는 `submit`의 검증 성공 분기에 연결하세요.

### 사이드바 설정 [#sidebar-settings]

[미리보기](/ko/blocks/sidebar-settings) · <a href="/downloads/sidebar-settings.zip" download>프로젝트 다운로드 (.zip)</a>

ZIP을 풀고 `sidebar-settings` 폴더에서 `cargo run`을 실행하세요.

기존 앱에 붙이려면 앱 루트에서 아래 명령을 실행하세요.

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/blocks/sidebar-settings/block.json
```

```rust
let settings = cx.new(|cx| crate::ui::sidebar_settings::SidebarSettings::new(window, cx));
```

`settings`를 `gpui::Entity<crate::ui::sidebar_settings::SidebarSettings>` 필드에 보관하고 `.child(self.settings.clone())`으로 표시하세요. 적용한 설정은 현재 세션에 유지됩니다.

[네오브루탈 로그인](/ko/directory/neobrutal#login)은 레지스트리에서 설치한 뒤 별도 창 예제의 `src/screen.rs`에서 `pub(crate) use crate::ui::neobrutal_login::Login as Screen;`을 사용하세요.

## 우리 팀의 블록 공유 [#publish]

공개 GitHub 저장소에 `block.json`과 여기에 나열한 소스 파일을 커밋합니다. [청구 대시보드 소스](https://github.com/andongmin94/gpui-deck/tree/main/blocks/billing-dashboard)에서 실제 파일 구성을 볼 수 있습니다.

```json
{
  "version": 1,
  "name": "billing-dashboard",
  "recipes": ["chart", "data-table"],
  "files": [
    { "source": "dashboard.rs", "target": "mod.rs" },
    { "source": "palette.rs", "target": "palette.rs" },
    { "source": "components/panel.rs", "target": "components/panel.rs" }
  ]
}
```

`name`은 Rust 모듈 디렉터리 이름을 정합니다. 예를 들어 `billing-dashboard`는 `billing_dashboard`가 됩니다. `recipes`에는 블록이 가져올 기본 레시피를 적습니다. `files`의 `source`는 매니페스트 기준 경로이고, `target`은 설치할 블록 모듈 안의 경로입니다. 진입 파일의 `target`을 `mod.rs`로 정하고 팀 팔레트, 전용 컴포넌트, 에셋도 목록에 추가하세요.

블록 이름은 영문 소문자로 시작하고 단어는 하이픈으로 구분합니다. 상대 파일 경로에는 영문자·숫자·밑줄·하이픈·점을 사용할 수 있습니다. 예를 들어 `brand/button.rs`를 `components/button.rs`에 설치할 수 있습니다.

`block.json`을 연 GitHub 파일 URL이나 `raw.githubusercontent.com` URL을 공유하세요. 같은 버전을 재현하려면 특정 커밋을 가리키는 링크를 사용하세요. 설치한 사람은 Rust 파일을 직접 수정할 수 있고, 같은 URL을 다시 추가해도 수정 내용이 유지됩니다. 빌드 전에 작성자의 소스를 확인하세요.

`gpui-deck diff --to src/ui`는 기본 레시피와 생성된 모듈 선언을 비교합니다. 팀이 작성한 블록 파일의 변경 사항은 앱 저장소의 Git diff에서 확인하세요.

## 같은 디자인의 컴포넌트와 블록 공유하기 [#share-collection]

[네오브루탈 레지스트리](https://github.com/andongmin94/gpui-deck/tree/main/registries/neobrutal)처럼 팀의 공개 GitHub 저장소에 Rust 소스와 항목별 매니페스트를 함께 올리세요. 네오브루탈 로그인 매니페스트는 개별 컴포넌트가 쓰는 버튼, 입력창, 팔레트 파일을 그대로 가리킵니다. 로그인 하나만 설치해도 세 파일이 함께 들어옵니다.

버튼만 설치했다면 `crate::ui::neobrutal_button::press_button("save", "저장")`을 렌더링하고 `.on_click(...)`에 동작을 연결하세요. 입력창은 `cx.new(...)` 안에서 `crate::ui::neobrutal_input::editor`로 상태를 한 번 만든 뒤, 렌더링할 때마다 `crate::ui::neobrutal_input::field`에 전달합니다.

공개 [`registry.json` 목록](https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/registry.json)에 각 항목의 매니페스트와 유형을 적으세요. 개별 항목은 `gpui-deck add` 뒤에 **항목 매니페스트** URL을 붙여 설치할 수 있습니다.

[디렉터리에서 레지스트리 등록 요청](/ko/directory#submit-registry)을 선택하면 GitHub 이슈 양식이 열립니다. 목록 URL과 설치할 수 있는 항목 매니페스트 URL 하나를 보내 주세요. 관리자가 제출 내용을 검토한 뒤 디렉터리에 추가합니다.

## 설치한 레지스트리 항목 실행 [#registry]

[Cargo 의존성](/ko/docs/installation)을 추가하고 아래 명령으로 Select를 설치하세요. 별도 창 예제의 `src/screen.rs`에서 `Screen` 별칭을 지우세요. `src/block_window.rs`에서는 `crate::screen::{TITLE, WINDOW_SIZE}`를 가져오고 `screen`을 만드는 한 줄을 아래 Rust 코드로 바꾸세요. `cargo run`을 실행하면 예제가 열립니다.

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/select.json
```

```rust
let screen = crate::ui::neobrutal_select::preview(window, cx);
```

내 앱의 데이터와 동작을 연결할 때는 같은 모듈의 컴포넌트 함수를 뷰에서 직접 호출하세요.

## 레지스트리 테마 적용

버튼과 테마를 같은 UI 디렉터리에 설치하세요. 렌더링할 때 테마의 팔레트를 넘기면 됩니다. 다크 모드는 `palette(true)`를 사용하세요.

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/button.json
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/theme-blue.json
```

```rust
let palette = crate::ui::neobrutal_theme_blue::palette(false);
let save = crate::ui::neobrutal_button::press_button_with_palette("save", "저장", palette);
```

같은 앱에서 프로젝트 대시보드에도 블루 테마를 적용하려면 템플릿을 추가하세요.

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/dashboard-template.json
```

`src/screen.rs`의 `Screen` 별칭을 아래 코드로 바꾸세요.

```rust
pub(crate) use crate::ui::neobrutal_dashboard_template::Dashboard as Screen;
```

`open_window` 안에서 `screen`을 만드는 한 줄을 아래 두 줄로 바꾼 뒤 `cargo run`으로 창을 여세요.

```rust
let palette = crate::ui::neobrutal_theme_blue::palette(true);
let screen = cx.new(|cx| Screen::new(palette, window, cx));
```

[뉴모피즘 레지스트리](/ko/directory/neumorphism)에서 각 항목을 직접 실행하고 설치 명령을 복사할 수 있습니다. 버튼과 세이지 테마를 같은 앱에 설치한 뒤, 버튼을 그릴 때 팔레트를 넘기세요. 다크 모드는 `palette(true)`를 사용합니다.

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neumorphism/button.json
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neumorphism/style-sage.json
```

```rust
let palette = crate::ui::neumorphism_style_sage::palette(false);
let save = crate::ui::neumorphism_button::press_button_with_palette("save", "저장", palette);
```
