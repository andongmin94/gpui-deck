---
title: すべてのガイド
description: "設定画面を組み立て、レシピをアプリに合わせて編集し、GitHub でブロックを共有する方法を紹介します。"
---

<Cards>
  <Card title="フォーム" href="/ja/docs/guides/forms/">
    ネイティブの設定フォームで入力状態、フィールドのラベル、検証エラーを結び付けます。
  </Card>
  <Card title="ナビゲーションとオーバーレイ" href="/ja/docs/guides/navigation-overlays/">
    タブとサイドバーで画面を切り替え、メニューやダイアログ、キーボード操作のヘルプを追加します。
  </Card>
  <Card title="レイアウトとデータ" href="/ja/docs/guides/layout-data/">
    スクロールできる表を組み込み、隣り合うパネルの幅を調整できるようにします。
  </Card>
  <Card title="レシピのコピー" href="/ja/docs/guides/recipes/">
    CLI でレシピとその依存関係をインストールし、アプリ内で Rust ソースを編集します。
  </Card>
  <Card title="ブロックの導入と共有" href="/ja/docs/guides/blocks/">
    GitHub の URL から画面を導入したり、チームの配色とコンポーネントを含むブロックを共有したりできます。
  </Card>
</Cards>
