[two-style サンプル](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/two_styles.rs)は、同じ
設定の動作を、コンパクトなダークと広々としたライトのプレゼンテーションで組み合わせています。その
Session actions メニューとサマリーの ContextMenu は、Dialog を開いたり、
アプリケーションの値を切り替えたり、AlertDialog を通じてプレビューのリセットを要求したりできます。HoverCard は
現在のプリセット、日付、メモの状態をプレビューし、プリセットのボタンは
通常の設定アクションを維持します。Collapsible にはプレビューのコントロールが入っています。
Search commands は Dialog 内で Command のクエリと結果リストを開きます。どちらのメニューも
同じアプリケーションのアクションをディスパッチします。Separator はコンテンツ領域間の
セマンティックな区切りを提供し、設定フォームには保持される複数行のメモが含まれます。
Compact は、アクティブなパネルを持つ Preferences、Help、Schedule、Presets のタブを使用します。
Settings は [Sidebar レシピ](../recipes/sidebar.mdx)と、現在のセクションのための名前付きの
Region を使用します。Help には Accordion があり、そのキーボードのセクションは、
非モーダルの Popover でガイドを開きます。Breadcrumb はそのガイドの場所を示し、
アプリケーションが所有する
[Kbd レシピ](../recipes/kbd.mdx)が、既存のキーボード操作を表示します。
すべてのスタイルはサンプル内にあります。

`gpui_deck::init(cx)` を呼び出し、ウィンドウを `gpui_deck::Root` 内にホストしてください。
状態のエンティティとその監視のサブスクリプションは、ビュー内に保持します。サンプルには、
完全なセットアップとアプリケーションが所有するスタイリングが示されています。

## 検証

既存の GPUI テストフレームワークは、選択と無効のメタデータ、向き、
フォーカスの移動、非アクティブなパネル、ポップアップの解除、コマンドのディスパッチ、そして
両方の外観とカタログにわたる代表的な構成フローをチェックします。構成テストは、コマンドが
Dialog を開くこと、展開せずにヘッダーでナビゲートすること、Popover が
開いているパネルを折りたたむこと、開閉コンテンツのマウント、プレビューのリセットの明示的な確認をカバーしています。
コンシューマーのフローは、コマンド検索から複数行の設定
フォームへの流れ、通常のフィールドと無効なフィールドでの Tab による移動、保持されるメモをカバーしています。
また、ツールチップのトリガー、Field のラベル/フィードバック、Dialog 内での検索可能なプリセット
選択 (クエリのキャンセルと保持される選択を含む) もカバーしています。
既存のフローは、キーボードとポインターによるコンテキストメニューのコマンドが
その Dialog を開くこと、および HoverCard のトリガーが通常のアクションと
フォーカスの復帰先を保持することも検証します。チェック付きのコマンドは、これらの同じフローを使って、両方のメニューホストで
アプリケーションの現在の値が反映されること、およびアクションとフォーカスの動作が変わらないことを確認します。
プリミティブのテストは、点の配置と
ポインターによるプレビューのタイミングを、それぞれを所有するレイヤーでカバーしています。
Breadcrumb の検証範囲は、そのネイティブな navigation/list/item のロール、
現在のページのメタデータ、および既存の Help フローでの合成された祖先のアクションです。そのフローは、静的なキーのヒントが
既存のコントロールにフォーカスを残すことも確認します。これらの契約では、ネイティブのスクリーンリーダーによる読み上げや、
パスとキーキャップの視覚的な外観は確認できません。
フルスイートは、独立したレシピのチェックを含め、Linux で一度だけ実行されます。Windows と
macOS は、レシピのみのテストを除外して、実際のコンシューマーの構成フローを実行し、
3 つのプラットフォームすべてがネイティブのサンプルをビルドします。これらは、デスクトップでのネイティブの
IME、スクリーンリーダー、DPI、視覚的なチェックの代わりにはなりません。
