## 請求ダッシュボードを導入する

[請求ダッシュボードのプレビュー](/ja/blocks/billing-dashboard/)でチャートと請求書テーブルを操作し、インストールする Rust ソースを確認できます。

### 新しいアプリとして実行 [#new-app]

<a href="/downloads/billing-dashboard.zip" download>請求ダッシュボードのプロジェクト</a>をダウンロードして展開し、`billing-dashboard` フォルダーでターミナルを開きます。[OS 別のビルドツール](/ja/docs/installation/)を準備してから実行します。

```sh
cargo run
```

### 既存のアプリに追加 [#existing-app]

Rust アプリに[インストールガイド](/ja/docs/installation/)の Cargo 依存関係を追加します。`curl` が使える環境で、アプリのルートから実行してください。

```sh
cargo install gpui-deck-cli --version 0.0.4 --locked
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/blocks/billing-dashboard/block.json
```

既定のインストール先は `src/ui` です。ダッシュボードとチームのパレットは `src/ui/billing_dashboard/` に入ります。チャートと請求書テーブルは同じパレットを使い、テーブルが必要とする入力グループ、ページ送り、空状態のレシピも一緒に入ります。別の UI モジュールを選ぶには `--to` を指定します。

`src/ui` を新しく追加した場合は、クレートのルートで `mod ui;` を宣言します。既存ビューのコンストラクターで `gpui::AppContext as _` をインポートし、ダッシュボードを一度だけ生成します。

```rust
let billing = cx.new(|cx| crate::ui::billing_dashboard::BillingDashboard::new(window, cx));
```

返り値を `gpui::Entity<crate::ui::billing_dashboard::BillingDashboard>` 型の `billing` フィールドに保持し、既存の GPUI Deck ウィンドウ内で `.child(self.billing.clone())` として表示します。

別の請求ウィンドウを開くには、以下の 2 ファイルを `src/` にコピーし、クレートのルートで `mod screen;` と `mod block_window;` を宣言します。起動時に `gpui_deck::init(cx)` の後で `block_window::open(cx)` を呼び出します。

<include lang="rust" meta='title="src/screen.rs"'>../../../../blocks/billing-dashboard/app/screen.rs</include>

<include lang="rust" meta='title="src/block_window.rs"'>../../../../blocks/starter/block_window.rs</include>

## 別のブロックを開く

新しいアプリにはプロジェクトの ZIP を使えます。既存の GPUI アプリでは[導入手順](#existing-app)に従って Cargo の依存関係と `mod ui;` を準備し、使いたい画面を追加してください。親ビューで `gpui::AppContext as _` をインポートし、コンストラクターで子ビューを一度だけ作成します。

### ログイン [#login]

[プレビュー](/ja/blocks/login) · <a href="/downloads/login.zip" download>プロジェクトをダウンロード (.zip)</a>

ZIP を展開し、`login` フォルダーで `cargo run` を実行します。

既存のアプリに追加する場合は、そのアプリのルートで以下を実行します。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/blocks/login/block.json
```

```rust
let login = cx.new(|cx| crate::ui::login::Login::new(window, cx));
```

`login` を `gpui::Entity<crate::ui::login::Login>` 型のフィールドに保存し、`.child(self.login.clone())` で表示します。フォームはローカルで入力を検証します。認証サービスは `submit` の検証成功時に接続してください。

### サイドバー付き設定画面 [#sidebar-settings]

[プレビュー](/ja/blocks/sidebar-settings) · <a href="/downloads/sidebar-settings.zip" download>プロジェクトをダウンロード (.zip)</a>

ZIP を展開し、`sidebar-settings` フォルダーで `cargo run` を実行します。

既存のアプリに追加する場合は、そのアプリのルートで以下を実行します。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/blocks/sidebar-settings/block.json
```

```rust
let settings = cx.new(|cx| crate::ui::sidebar_settings::SidebarSettings::new(window, cx));
```

`settings` を `gpui::Entity<crate::ui::sidebar_settings::SidebarSettings>` 型のフィールドに保存し、`.child(self.settings.clone())` で表示します。適用した設定は現在のセッションに保持されます。

[Neobrutal ログイン](/ja/directory/neobrutal#login)はレジストリからインストールし、別ウィンドウの例の `src/screen.rs` で `pub(crate) use crate::ui::neobrutal_login::Login as Screen;` を使います。

## チームのブロックを公開する [#publish]

公開 GitHub リポジトリに `block.json` とそこに記載したソースファイルをコミットします。[請求ダッシュボードのソース](https://github.com/andongmin94/gpui-deck/tree/main/blocks/billing-dashboard)に一式があります。

```json
{
  "version": 1,
  "name": "billing-dashboard",
  "recipes": ["chart", "data-table"],
  "files": [
    { "source": "dashboard.rs", "target": "mod.rs" },
    { "source": "palette.rs", "target": "palette.rs" },
    { "source": "components/panel.rs", "target": "components/panel.rs" }
  ]
}
```

`name` が Rust モジュールのディレクトリ名になります。例えば `billing-dashboard` は `billing_dashboard` になります。`recipes` にはブロックが使う標準レシピを指定します。`files` の `source` はマニフェストからの相対パス、`target` はインストール先のブロック内の相対パスです。エントリーポイントの `target` は `mod.rs` にし、独自のパレット、コンポーネント、アセットも追加してください。

ブロック名は小文字で始め、単語をハイフンで区切ります。相対パスには英数字、アンダースコア、ハイフン、ピリオドを使用します。例えば `brand/button.rs` を `components/button.rs` に配置できます。

マニフェストの GitHub ファイル URL または `raw.githubusercontent.com` の URL を共有します。バージョンを固定するにはコミットを指すリンクを使います。利用者は Rust ソースを直接編集できます。同じ URL を再度指定しても編集は保持されます。ビルド前に作者のソースを確認してください。

`gpui-deck diff --to src/ui` は同梱レシピと生成されたモジュール宣言を比較します。チームのブロックファイルの変更はアプリ側の Git diff で確認します。

## コレクションを共有する [#share-collection]

[Neobrutal レジストリ](https://github.com/andongmin94/gpui-deck/tree/main/registries/neobrutal)のように、チームの公開 GitHub リポジトリに Rust ソースと項目ごとのマニフェストを置きます。ログイン画面のマニフェストは、個別に配布するボタン、入力欄と共通のパレットを参照するので、ログイン画面を追加するとすべて揃います。

ボタンだけを追加した場合は、`crate::ui::neobrutal_button::press_button("save", "保存")` に `.on_click(...)` を付けて描画します。入力欄では `cx.new(...)` の中で `crate::ui::neobrutal_input::editor` を使って状態を一度生成し、描画のたびに `crate::ui::neobrutal_input::field` に渡します。

公開の [`registry.json` カタログ](https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/registry.json)に各項目のマニフェストと種類を記載します。`gpui-deck add` には、インストールする**項目のマニフェスト**の URL を渡します。

[レジストリ一覧から掲載を申請](/ja/directory#submit-registry)すると、GitHub の Issue フォームが開きます。カタログの URL と、インストールできる項目のマニフェスト URL を一つ添えてください。メンテナーが内容を確認してから掲載します。

## 導入したレジストリ項目を実行する [#registry]

[Cargo の依存関係](/ja/docs/installation)を追加し、以下のコマンドで Select をインストールします。別ウィンドウの例の `src/screen.rs` から `Screen` の別名を削除します。`src/block_window.rs` で `crate::screen::{TITLE, WINDOW_SIZE}` をインポートし、`screen` を生成する行を以下の Rust コードに置き換えます。`cargo run` で例を実行できます。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/select.json
```

```rust
let screen = crate::ui::neobrutal_select::preview(window, cx);
```

独自のデータや動作を渡すには、同じモジュールのコンポーネント関数をビューから直接呼び出します。

## レジストリのテーマを使う

ボタンとテーマを同じ UI ディレクトリに追加して、描画時にパレットを渡します。ダーク配色には `palette(true)` を使います。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/button.json
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/theme-blue.json
```

```rust
let palette = crate::ui::neobrutal_theme_blue::palette(false);
let save = crate::ui::neobrutal_button::press_button_with_palette("save", "保存", palette);
```

同じアプリでプロジェクトダッシュボードにもブルーテーマを適用するには、テンプレートを追加します。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/dashboard-template.json
```

`src/screen.rs` の `Screen` の別名を次のインポートに置き換えます。

```rust
pub(crate) use crate::ui::neobrutal_dashboard_template::Dashboard as Screen;
```

`open_window` 内で `screen` を作成する行を次の 2 行に置き換え、`cargo run` で起動します。

```rust
let palette = crate::ui::neobrutal_theme_blue::palette(true);
let screen = cx.new(|cx| Screen::new(palette, window, cx));
```

## ニューモーフィズムのコレクションを使う

[ニューモーフィズムのレジストリ](/ja/directory/neumorphism)で各項目のプレビューとインストールコマンドを確認できます。ボタンとセージのテーマを同じアプリにインストールし、ボタンの描画時にパレットを渡します。ダークモードには `palette(true)` を使います。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neumorphism/button.json
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neumorphism/style-sage.json
```

```rust
let palette = crate::ui::neumorphism_style_sage::palette(false);
let save = crate::ui::neumorphism_button::press_button_with_palette("save", "保存", palette);
```
