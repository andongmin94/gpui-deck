## 請求ダッシュボードを導入する

[請求ダッシュボードのプレビュー](/ja/blocks/billing-dashboard/)でチャートと請求書テーブルを操作し、インストールする Rust ソースを確認できます。

Rust アプリに[インストールガイド](/ja/docs/installation/)の Cargo 依存関係を追加します。`curl` が使える環境で、アプリのルートから実行してください。

```sh
cargo install gpui-deck-cli --version 0.0.2 --locked
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/blocks/billing-dashboard/block.json
```

既定のインストール先は `src/ui` です。ダッシュボードとチームのパレットは `src/ui/billing_dashboard/` に入ります。チャートと請求書テーブルは同じパレットを使い、テーブルが必要とする入力グループ、ページ送り、空状態のレシピも一緒に入ります。別の UI モジュールを選ぶには `--to` を指定します。

次のコードを `src/main.rs` に置き、`cargo build` でビルドするか、`cargo run` でウィンドウを開きます。

```rust
mod ui;

use gpui::AppContext as _;
use ui::billing_dashboard::BillingDashboard as Screen;

fn main() {
    gpui_platform::application().run(|cx| {
        gpui_deck::init(cx);
        cx.open_window(Default::default(), |window, cx| {
            let screen = cx.new(|cx| Screen::new(window, cx));
            cx.new(|cx| gpui_deck::Root::new(screen, window, cx))
        })
        .expect("open block window");
        cx.activate(true);
    });
}
```

## 別のブロックを開く

使いたいブロックのページでインストールコマンドをコピーして実行します。上のコードの `use ... as Screen` を、その画面に対応する行に置き換えてください。

| ブロック | インポート |
| --- | --- |
| [ログイン](/ja/blocks/login) | `use ui::login::Login as Screen;` |
| [サイドバー付き設定](/ja/blocks/sidebar-settings) | `use ui::sidebar_settings::SidebarSettings as Screen;` |
| [Neobrutal ログイン](/ja/directory/neobrutal) | `use ui::neobrutal_login::Login as Screen;` |

## チームのブロックを公開する [#publish]

公開 GitHub リポジトリに `block.json` とそこに記載したソースファイルをコミットします。[請求ダッシュボードのソース](https://github.com/andongmin94/gpui-deck/tree/main/blocks/billing-dashboard)に一式があります。

```json
{
  "version": 1,
  "name": "billing-dashboard",
  "recipes": ["chart", "data-table"],
  "files": [
    { "source": "dashboard.rs", "target": "mod.rs" },
    { "source": "palette.rs", "target": "palette.rs" },
    { "source": "components/panel.rs", "target": "components/panel.rs" }
  ]
}
```

`name` が Rust モジュールのディレクトリ名になります。例えば `billing-dashboard` は `billing_dashboard` になります。`recipes` にはブロックが使う標準レシピを指定します。`files` の `source` はマニフェストからの相対パス、`target` はインストール先のブロック内の相対パスです。エントリーポイントの `target` は `mod.rs` にし、独自のパレット、コンポーネント、アセットも追加してください。

ブロック名は小文字で始め、単語をハイフンで区切ります。相対パスには英数字、アンダースコア、ハイフン、ピリオドを使用します。例えば `brand/button.rs` を `components/button.rs` に配置できます。

マニフェストの GitHub ファイル URL または `raw.githubusercontent.com` の URL を共有します。バージョンを固定するにはコミットを指すリンクを使います。利用者は Rust ソースを直接編集できます。同じ URL を再度指定しても編集は保持されます。ビルド前に作者のソースを確認してください。

`gpui-deck diff --to src/ui` は同梱レシピと生成されたモジュール宣言を比較します。チームのブロックファイルの変更はアプリ側の Git diff で確認します。

## コレクションを共有する

[Neobrutal レジストリ](https://github.com/andongmin94/gpui-deck/tree/main/registries/neobrutal)のように、チームの公開 GitHub リポジトリに Rust ソースと項目ごとのマニフェストを置きます。ログイン画面のマニフェストは、個別に配布するボタン、入力欄と共通のパレットを参照するので、ログイン画面を追加するとすべて揃います。

ボタンだけを追加した場合は、`ui::neobrutal_button::press_button("save", "保存")` に `.on_click(...)` を付けて描画します。入力欄では `cx.new(...)` の中で `ui::neobrutal_input::editor` を使って状態を一度生成し、描画のたびに `ui::neobrutal_input::field` に渡します。

`registry.json` に各項目のマニフェストを列挙してコレクションを紹介できます。`gpui-deck add` にはインストールしたい**項目のマニフェスト**の GitHub URL を渡します。[レジストリ一覧](/ja/directory)で実例を確認できます。

## 導入したレジストリ項目を実行する [#registry]

[Cargo の依存関係](/ja/docs/installation)を追加し、一覧から項目を選びます。Select を使う場合は以下のコマンドで追加します。上のウィンドウ例から `Screen` のインポートを削除し、`screen` を生成する行を以下の Rust コードに置き換えます。`cargo run` でサイトと同じ例をネイティブウィンドウで実行できます。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/select.json
```

```rust
let screen = ui::neobrutal_select::preview(window, cx);
```

独自のデータや動作を渡すには、同じモジュールのコンポーネント関数をビューから直接呼び出します。

## レジストリのテーマを使う

ボタンとテーマを同じ UI ディレクトリに追加して、描画時にパレットを渡します。ダーク配色には `palette(true)` を使います。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/button.json
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/theme-blue.json
```

```rust
let palette = ui::neobrutal_theme_blue::palette(false);
let save = ui::neobrutal_button::press_button_with_palette("save", "保存", palette);
```

同じアプリでプロジェクトダッシュボードにもブルーテーマを適用するには、テンプレートを追加します。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neobrutal/dashboard-template.json
```

上のウィンドウの例で、`use … as Screen;` の行を次のインポートに置き換えます。

```rust
use ui::neobrutal_dashboard_template::Dashboard as Screen;
```

`open_window` 内で `screen` を作成する行を次の 2 行に置き換え、`cargo run` で起動します。

```rust
let palette = ui::neobrutal_theme_blue::palette(true);
let screen = cx.new(|cx| Screen::new(palette, window, cx));
```

## ニューモーフィズムのコレクションを使う

[ニューモーフィズムのレジストリ](/ja/directory/neumorphism)で各項目のプレビューとインストールコマンドを確認できます。ボタンとセージのテーマを同じアプリにインストールし、ボタンの描画時にパレットを渡します。ダークモードには `palette(true)` を使います。

```sh
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neumorphism/button.json
gpui-deck add https://github.com/andongmin94/gpui-deck/blob/main/registries/neumorphism/style-sage.json
```

```rust
let palette = ui::neumorphism_style_sage::palette(false);
let save = ui::neumorphism_button::press_button_with_palette("save", "保存", palette);
```
