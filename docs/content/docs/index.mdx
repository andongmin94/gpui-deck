---
title: Introduction
description: A source-owned, headless UI foundation for Rust and GPUI.
---

The library owns control behavior, state, focus and accessibility semantics.
Applications own their component source, layout, colors, typography and assets.
Headless separates control behavior from application-owned presentation; the
examples render native GPUI windows, and the previews on this site run the same
components in the browser through GPUI's web backend.

GPUI Design currently includes 42 public library families and 23 copyable
presentation recipes. Every entry of the shadcn/ui catalogue has an implemented
scope or a platform mapping, with its limits recorded in
[Coverage and status](./coverage.mdx).
