---
title: すべてのレシピ
description: "ライブラリの上に構築された、コピー可能なプレゼンテーションソースです。ローカル CLI でインストールして、自分のものにできます。"
---

<Cards>
  <Card title="Alert" href="/ja/docs/recipes/alert/">
    インラインのタイトルと説明。破壊的スタイルは別に指定でき、緊急性は明示的に指定します。
  </Card>
  <Card title="Aspect Ratio" href="/ja/docs/recipes/aspect-ratio/">
    有限で正の幅/高さの比率を持つ、クリップされたメディアフレーム。コンテンツはアプリケーションが所有します。
  </Card>
  <Card title="Attachment" href="/ja/docs/recipes/attachment/">
    ファイル名、渡されたメディアタイプとサイズ、任意の既存アクションを持つ、名前付きのファイルメタデータのグループ。
  </Card>
  <Card title="Avatar" href="/ja/docs/recipes/avatar/">
    明示的なフォールバックテキストを持つ名前付きの円形画像。GPUI の画像ローダーとキャッシュを使用します。名前付きの「+N」オーバーフローを持つ、重なり合う AvatarGroup もあります。
  </Card>
  <Card title="Badge" href="/ja/docs/recipes/badge/">
    secondary と accent の外観を持つ静的なラベル。
  </Card>
  <Card title="Bubble" href="/ja/docs/recipes/bubble/">
    受信/送信のサーフェス、グループ化された作成者/時刻のラベル、渡されたリアクション。
  </Card>
  <Card title="Button Group" href="/ja/docs/recipes/button-group/">
    任意のテキストスロットを持つ、連結された水平/垂直のボタン。
  </Card>
  <Card title="Card" href="/ja/docs/recipes/card/">
    見出し、説明、ヘッダーのアクション、本体、フッターを持つ名前付きのリージョン。
  </Card>
  <Card title="Code Block" href="/ja/docs/recipes/code-block/">
    読み取り専用の複数行コード、全文を正確にコピーする Copy アクション、キーボードで操作できる、範囲が制限された 2 軸のスクロール。
  </Card>
  <Card title="Data Table" href="/ja/docs/recipes/data-table/">
    テキストのフィルタリング/ソート、ページネーション、ページ/行のチェックボックス選択、列の表示切り替え、安定した ID による行アクション。
  </Card>
  <Card title="Empty" href="/ja/docs/recipes/empty/">
    見出し、説明、任意のメディア、渡されたアクションを持つ、名前付きの静的なグループ。
  </Card>
  <Card title="Input Group" href="/ja/docs/recipes/input-group/">
    既存の入力を囲む共有フレーム。先頭/末尾のアドオンと水平/垂直のレイアウトを備えます。
  </Card>
  <Card title="Item" href="/ja/docs/recipes/item/">
    タイトル、説明、任意のメディア、ヘッダー、フッター、末尾のアクションを持つ、名前付きのコンテンツ行。
  </Card>
  <Card title="Kbd" href="/ja/docs/recipes/kbd/">
    静的で名前付きのキーキャップと、+ で結合されたキーの組み合わせ。
  </Card>
  <Card title="Marker" href="/ja/docs/recipes/marker/">
    装飾的な区切りの間に置く、名前付きの日付/ステータスラベル。テキストは折り返され、フォーカスストップはありません。
  </Card>
  <Card title="Message" href="/ja/docs/recipes/message/">
    作成者/時刻のメタデータ、折り返される段落、任意の既存アクションを持つ読み取り専用のコメント。
  </Card>
  <Card title="Pagination" href="/ja/docs/recipes/pagination/">
    制御される前へ/次へのボタン、現在のページのテキスト、空/最初/最後のページの境界。
  </Card>
  <Card title="Sheet" href="/ja/docs/recipes/sheet/">
    Dialog 上の 4 辺のモーダルプレゼンテーション。ビューポートに制限されたサイズ、固定のヘッダー/フッター、スクロールする 1 つの本体。
  </Card>
  <Card title="Sidebar" href="/ja/docs/recipes/sidebar/">
    名前付きでグループ化されたナビゲーション、通常の Button、現在のページのメタデータ、任意の全体/グループの Collapsible 状態、任意のアイコンレール。
  </Card>
  <Card title="Skeleton" href="/ja/docs/recipes/skeleton/">
    アプリケーションがサイズと形を制御する、静的で装飾的なプレースホルダー。
  </Card>
  <Card title="Spinner" href="/ja/docs/recipes/spinner/">
    GPUI の reduced-motion 設定を尊重する、回転する円弧を持つ名前付きの不定 Progress。
  </Card>
  <Card title="Trace" href="/ja/docs/recipes/trace/">
    既存の Collapsible のライフサイクル上にある、展開可能な要約と名前付きの読み取り専用の詳細。任意のアクションを持てます。
  </Card>
  <Card title="Typography" href="/ja/docs/recipes/typography/">
    明示的なレベルを持つ名前付きの見出し、ネイティブなインラインコードのテキストランを持つ段落、独立して名前付けされるコード要素。
  </Card>
</Cards>
