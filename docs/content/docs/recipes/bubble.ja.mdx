カタログは、`crates/base/examples/recipes` の下に、ソースを自分で所有する
2 つの独立したプレゼンテーションを追加します。`bubble.rs` は Bubble のカタログエントリーで、
受信/送信の配置、グループ化された作成者/時刻のメタデータ、折り返されるメッセージの
本文、渡されたリアクションのアクションを備えます。起動とフォーカスは既存の Button が担い、
メッセージのグループ化とリアクションの値は会話ビューに属します。トランスポート、
永続化、別のメッセージ状態エンジンは追加しません。

`chart.rs` は公開されている Chart ファミリーのためのプレゼンテーションで、
2 つ目のカタログエントリーとしては数えません。ネイティブのキャンバスによる折れ線/棒/面、積み上げ、
円/ドーナツ、レーダーのパス、軸またはスポークのラベル、
シリーズの Toggle、確認した値の表示、同じデータの Table を提供します。その色の配列、
レイアウト、書式はアプリケーションが所有します。共有される Chart の契約については、
[レイアウトとデータのガイド](../guides/layout-data.mdx)をご覧ください。

`cargo run -p gpui-design --example catalogue --locked` を実行すると、
これらを、それぞれ MessageScroller/Questionnaire および Carousel/Direction とともに試せます。既存の
`two_styles` サンプルは、引き続きセッション指向のレシピをホストします。
