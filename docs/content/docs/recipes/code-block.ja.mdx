[`code_block.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/code_block.rs) は、読み取り専用の
複数行コードを、既存の Button、GPUI のクリップボード、ScrollArea と合成します。

```rust
CodeBlock::new(
    "session-configuration",
    configuration_json,
    "Session configuration",
    &configuration_scroll,
    &configuration_focus,
    palette,
);
```

`ScrollHandle` と `FocusHandle` は、アプリケーションで保持してください。渡されたラベルは
Copy ボタンの横に表示され、そのアクセシブルな名前は `Copy {label}` です。
コードはネイティブな Code セマンティクスを公開し、その完全な元のテキストをアクセシブルな
名前とします。ビューポートはキーボードのフォーカス対象で、Copy は
既存のポインター、Enter、Space、フォーカスの動作を持つ通常の Button のままです。
レシピは、テキスト入力ノード、エディターの状態、選択モデルを追加しません。

デフォルトのフレームは高さ 12 rem で、利用可能な幅いっぱいに広がります。そのヘッダーは、
範囲が制限されたコードのビューポートの外にあります。`Styled` でフレームをカスタマイズできます。ScrollArea が
長い本体や長い行を収められるように、高さと幅には上限を設けたままにしてください。コードには
パレットのコードフォントと前景色を使用します。GPUI ネイティブのテキストレイアウトが、
渡された行をソフトラップなしで表示し、水平方向と垂直方向のオーバーフローは
同じ ScrollArea の中に収まります。レシピは、コードの解析も、シンタックス
ハイライト、行番号、仮想化された描画の追加も行いません。

Copy は、画面外のコンテンツや空文字列も含め、渡された文字列全体を `App::write_to_clipboard` に送ります。
空白、改行コード、末尾の改行のトリム、正規化、置換は行いません。LF、CRLF、Unicode のコンテンツは
コピーされるペイロードにそのまま保持されます。可視のテキストは GPUI が整形します。レシピは、
追加のタブストップのポリシーや、見た目上の CRLF の正規化を定義しません。
コピー済みの状態を示す別のタイマーや、自動的なアナウンスはありません。

コードのビューポート自体にフォーカスがあるとき、修飾キーなしの矢印キーはそれぞれの
軸でスクロールし、Page Up/Down は縦にスクロールし、Home は左上に戻り、
End は右下に移動します。オフセットはコンテンツのスクロール範囲内に収まります。
Tab と Shift-Tab は通常の移動を維持し、Escape は囲んでいるモーダルが利用でき、
修飾キーはアプリケーションに任されます。Copy ボタンの
キーイベントは Button の契約に従います。コード上でのホイール操作は、端に達しても
そのビューポート内にとどまります。親の Sheet を動かすには、その外側でスクロールしてください。

どちらの外観でも、CodeBlock は Help の State ownership パネルで、
ソースパスの識別子の前に使われています。コンシューマーは、保持されている現在の設定を、既存の `serde_json` の依存関係で
JSON としてシリアライズします。これは表示とコピーのための
スナップショットであり、コピーしても設定を解析したり適用したりしません。サンプルでは、
コンシューマーのビルダーをメインの描画関数から分離し、既存の
Sheet、フォーカスの封じ込め、親のスクロールを再利用しています。Typography は引き続き
文章と短いインラインコードを扱い、CodeBlock は範囲が制限された複数行のプレゼンテーションを担います。
