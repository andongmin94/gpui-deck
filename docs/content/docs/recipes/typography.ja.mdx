[`typography.rs`](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/recipes/typography.rs) は、`Heading`、
`Paragraph`、`InlineCode` を 1 つのプレゼンテーションレシピとして提供します。GPUI がテキストのシェーピング、
レイアウト、描画を担います。アプリケーションは、コンテンツ、アウトラインのレベル、フォントの
選択、利用可能な幅、周囲の余白を用意します。

```rust
Heading::new("help-title", "Help", 2, palette);

Paragraph::new("state-ownership", palette)
    .text("The application retains ")
    .code("DialogState")
    .text(" and ")
    .code("InputState")
    .text(" while panels are closed.");

InlineCode::new(
    "help-source",
    "crates/base/examples/two_styles.rs",
    palette,
);
```

`Heading::new` には、正のネイティブな見出しレベルが必要です。その可視のテキストが、
完全なアクセシブルな名前にもなります。レベルはコンテンツのアウトラインから選んでください。
レベルを変えると、デフォルトの視覚的なサイズとは独立して、セマンティックな階層が変わります。どのレベルも
`1.25 * palette.font_size` の semibold から始まります。
異なる視覚的なスケール、色、余白には、通常の `Styled` による調整を使用してください。

`Paragraph::text` と `Paragraph::code` は、渡されたテキストを順に追加し、
空白を挿入したりマークアップを解釈したりしません。句読点と空白は
テキストの区間に含めてください。1 つのネイティブな `StyledText` が段落全体を整形するため、
インラインコードも同じテキストの流れと行の折り返しの一部のままです。段落の
デフォルトは、通常の折り返し、パレットの本文サイズと前景色、フォントサイズの 1.5 倍の
行の高さです。親には利用可能な幅を与え、長いテキストのために高さは自動のままにしてください。
レシピは、切り詰め、固定の高さ、独立したスクロールを追加しません。オーバーフローは、周囲の Sheet/ScrollArea のコンテンツが担います。

段落はネイティブな Paragraph セマンティクスを公開し、連結された全文を
1 つのアクセシブルな名前とします。そのコード範囲には、ネイティブなテキストランのスタイルとして、コンシューマーのコードフォントと
背景が使われます。GPUI は、スタイル付きの範囲ごとのアクセシビリティのロールを公開しないため、これらの範囲は個別の Code ノードを作りません。
コードが独自の要素を必要とする場合は、`InlineCode` が、個別に名前付けされた
ネイティブな Code 要素を提供します。コードが文章の中に属する場合は、`Paragraph::code` を使用してください。
3 つの型はすべて静的なテキストで、フォーカスストップやキーボードアクションを追加しません。

コンシューマーの `palette.code_font_family` が、要求するコードフォントを選びます。
サンプルは、Linux では DejaVu Sans Mono、Windows では Consolas、macOS では Menlo を要求します。
アプリケーションは、自身の環境に適したフォントを用意してください。
`Styled` は、各要素のレイアウトとテキストのプレゼンテーションを制御します。Paragraph のコード
範囲は、本文のテキストの中で、明示的なコードフォントと背景のスタイルを保ちます。
表示サイズを変えても、Heading のネイティブなレベルや、アクセシブルな名前に使われる
テキストは変わりません。

どちらの外観も、Help タブでこのレシピを使用しています。レベル 2 の Help の見出しが、
既存のレベル 3 の Accordion の見出しの上にあり、パネルには、保持されるアプリケーションの状態についての文章と、
独立して名前付けされたソースの識別子が含まれます。
キーボードヘルプのポップアップには、既存の Breadcrumb のアクションと Kbd のヒントを保ったまま、簡潔な見出しが加わります。より長い説明は、Sheet の
スクロールする本体の中にあります。デバッグ描画時のスタック使用量を抑えるため、コンシューマーのビルダーは小さなヘルパー関数に分けています。

このレシピは、テキストのプレゼンテーションとメタデータを提供します。Markdown の解析、シンタックス
ハイライト、コードのコピー、テキストの編集、複数行の Code Block の構成は、
そのスコープの外です。保持される状態や、2 つ目のテキストレンダラーは導入しません。
