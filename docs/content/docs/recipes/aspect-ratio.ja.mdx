[`aspect_ratio.rs`](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/recipes/aspect_ratio.rs) は、
GPUI の既存のアスペクト比レイアウトを使った、クリップされたメディアフレームを提供します。

```rust
AspectRatio::new("recording-frame", 16. / 9.)
    .w(px(320.))
    .rounded(palette.radius)
    .bg(palette.field)
    .child(media)
```

比率は幅を高さで割った値で、有限かつ正である必要があります。デフォルトの
幅は親いっぱいに広がります。親に明確な幅を持たせるか、フレームに `.w(...)` を設定してください。
高さは自動のままにして、GPUI が幅から導出できるようにします。明示的な
高さや最小/最大の制約は、GPUI の通常のレイアウトルールに従い、
希望する比率を上書きすることがあります。

子要素は、フレームいっぱいに広がる絶対配置のコンテナー内に置かれるため、その固有のサイズが
高さを決めることはありません。はみ出したコンテンツは、フレーム外でのポインター操作も含めてクリップされます。
コンテナーを埋めたい画像やその他の子要素には `.size_full()` を指定し、画像の object fit はその子要素で選んでください。
フレームは、アクセシビリティのロール、名前、フォーカスストップ、保持される状態を追加しません。メディアの
子要素が、自身のアクセシブルな説明とインタラクションを提供します。背景、
角丸、その他のプレゼンテーションは、`Styled` を通じてアプリケーションに属します。

プリセットの HoverCard は、現在のセッション名を含む、イメージとしての録画フレームを表示します。
Presentation には 4:3、その他のプリセットや未選択の場合には 16:9 を使用します。
保持されているプリセットを変更すると、次の描画で比率が変わり、
セッション名を編集すると、表示されるテキストが変わります。渡された子要素には、
フォーマットを説明するネイティブな Image の名前があります。プレビューは録画を作成せず、
HoverCard の非インタラクティブなコンテンツにコントロールを追加することもありません。
