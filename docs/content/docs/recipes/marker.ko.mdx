[`marker.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/marker.rs)는 기존 장식용
Separator 두 개 사이에 정적 레이블을 둡니다. 애플리케이션의 날짜나 상태 경계에 맞는
텍스트를 전달하세요.

```rust
Marker::new("schedule-marker", "Selected date · 2026-11-09", palette);
```

레이블은 네이티브 Label 시맨틱을 노출하며 보이는 전체 텍스트를 접근 가능한 이름으로
사용합니다. 감싸는 레이아웃에는 역할이나 이름이 없고, 두 Separator 모두
`decorative(true)`를 사용해 네이티브 역할과 방향을 생략합니다. 따라서 마커는 구분선
시맨틱을 중복하지 않고 의미 있는 레이블 하나만 제공합니다. 포커스 핸들, Tab 스톱, 액션,
라이브 영역 알림은 추가하지 않습니다.

프레임은 사용 가능한 너비를 채웁니다. 가운데 정렬된 레이블은 팔레트의 본문 크기와 흐린
색상, 글꼴 크기의 1.5배 줄 높이, 일반 줄바꿈을 사용하며 프레임 너비의 최대 75%를
차지합니다. 두 가로선은 두께가 1픽셀이고 팔레트의 테두리 색상을 사용하며 남은 공간을
나눠 갖습니다. 긴 텍스트는 잘리지 않고 세로로 늘어날 수 있습니다. `Styled`가 프레임과
상속되는 텍스트 표현을 제어합니다. 너비는 제한하고 레이블 높이는 늘어날 수 있게 두세요.
레시피는 GPUI의 기존 텍스트 레이아웃을 사용하며 텍스트 렌더러나 타임라인 상태를 추가하지
않습니다.

두 모양 모두 Schedule의 DatePicker와 메모/계획 창 사이에 Marker를 둡니다. 소비자 코드는
`CalendarState::selection().first_date()`를 읽어 `Selected date · YYYY-MM-DD`로
서식화하며, 선택이 비어 있으면 `No date selected`를 표시합니다. 선택을 확정하지 않고
캘린더 커서만 옮기면 이 경계는 바뀌지 않습니다. 날짜 서식은 애플리케이션이 소유하며,
마커는 녹화를 시작하거나 두 번째 선택 날짜를 관리하지 않습니다.
