[`badge.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/badge.rs) は、静的で名前付きのラベルです。
デフォルトの外観は secondary で、`.accent(true)` を指定するとパレットの accent の
色を使用します。サンプルでは、この 2 つの外観で、実際のカーソルとツールバーの設定を表示しています。

```rust
Badge::new("cursor-status", "Cursor visible", palette).accent(true)
```

Badge は、Tab ストップ、ボタンアクション、押下状態、ライブアナウンスを追加しません。そのテキストは、
色に頼らずに状態を説明する必要があります。インタラクティブなチップには、
既存の Button または Toggle にアプリケーションのスタイリングを付けて使用してください。
