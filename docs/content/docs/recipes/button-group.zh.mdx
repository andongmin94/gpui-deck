[`button_group.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/button_group.rs) 为相关的
Button 提供一个边框和装饰性分隔符。它接受现有的 `Button`
实例，应用相连的样式，并保留它们的标识、动作、
禁用状态和各自的 Tab 停靠点。

```rust
ButtonGroup::new("calendar-month", "Calendar month", palette)
    .axis(Axis::Horizontal)
    .button(previous_month_button)
    .text("November 2026")
    .button(next_month_button)
    .w_full()
```

默认是水平；`Axis::Vertical` 会堆叠同样的各部分。`text` 是
没有焦点停靠点的静态标签。`Styled` 允许覆盖边框和尺寸。
由于外边框归该组所有，焦点使用 accent 填充。该组
不增加方向键导航或按下值状态；需要多个按下值并带漫游焦点时，
仍应使用 `ToggleGroup`。
