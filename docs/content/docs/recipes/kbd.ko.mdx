[`kbd.rs`](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/recipes/kbd.rs)는 정적인 개별 키캡과
키 조합을 제공합니다. 각 Kbd는 보이는 텍스트를 기본 네이티브 Label 이름으로 사용합니다.
기호 키에는 읽을 수 있는 이름을 명시적으로 지정하세요.

```rust
Kbd::new("guide-up-key", "↑", palette)
    .accessibility_label("Arrow up");

KbdGroup::new("context-menu-shortcut", palette)
    .key(Kbd::new("context-menu-shift", "Shift", palette))
    .key(Kbd::new("context-menu-f10", "F10", palette));
```

`KbdGroup`은 전달된 순서를 유지하며 키캡 사이에 `+`를 넣습니다. 네이티브 Group에는 반복되는
이름이 없고, 각 키는 자신의 읽을 수 있는 Label을 유지합니다. Shift+Tab처럼 함께 누르는 키에는
그룹을 사용하세요. Enter 또는 Space, 화살표 키처럼 대안을 보여 줄 때는 독립된 Kbd 요소를
일반 애플리케이션 레이아웃으로 배치하세요.

두 타입 모두 `Styled`를 구현합니다. 팔레트는 키캡의 필드 색상, 테두리, 모서리 반경, 전경색,
글꼴 크기와 그룹 구분자에 쓰는 흐린 텍스트를 제공합니다. 키 레이블과 플랫폼별 글리프 선택은
애플리케이션이 소유합니다. 레시피에는 포커스 스톱, 액션, 키 바인딩 등록, 단축키 실행이
없으며, 연결된 컨트롤이 이미 제공하는 바인딩을 표시할 뿐입니다.

예제의 Help → Keyboard 가이드는 Tab, Shift+Tab, 화살표, Enter/Space, Escape를 각각의 기존
동작 설명과 함께 보여 줍니다. 요약은 기존 ContextMenu를 위한 Shift+F10을 표시합니다. 일반
힌트 텍스트를 이 키캡으로 바꿔도 키보드 명령이나 다른 포커스 대상이 추가되지 않습니다.
