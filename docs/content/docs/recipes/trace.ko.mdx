title: Trace
description: "기존 Collapsible 수명 주기 위에 구축된, 펼칠 수 있는 요약과 이름 있는 읽기 전용 세부 정보이며 선택적인 액션을 갖습니다."
---

[`trace.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/trace.rs)는 이름 있는 읽기 전용
세부 정보와 선택적인 애플리케이션 액션으로 펼쳐지는 요약을 표시합니다. 기존 Collapsible
부분, Button 동작, Typography의 Paragraph를 조합합니다.

```rust
let disclosure = cx.new(CollapsibleState::new);
// Retain this entity and observe it so the application view redraws.

Trace::new(
    "settings-trace",
    &disclosure,
    "Current settings · MiniCast",
    "Current settings details",
    detail_text,
    palette,
)
.action(close_details_button)
```

전달된 `Entity<CollapsibleState>`는 애플리케이션이 소유하고 관찰합니다. 초기 상태는
`default_open`으로 구성하고, 이후 변경에는 기존 `set_open`과 `set_disabled` 메서드를
사용하세요. 닫혀 있는 동안에도 루트와 트리거를 마운트해 두세요. Trace는 추가 펼침 상태, 이벤트
타입, 데이터 수집, 실행 컨트롤러를 제공하지 않습니다.

기존 Collapsible 루트는 Tab이 아닌 포커스 범위를 갖는, 이름 없는 네이티브 Group입니다.
트리거는 전체 요약으로 이름 붙은 Button이며, CollapsibleTrigger가 제공하는 네이티브 펼침 및
비활성화 메타데이터를 갖습니다. 보이는 펼침 표시는 역할이나 이름을 추가하지 않습니다.
트리거로 열면 포커스는 트리거에 남으며, 일반 Tab 이동으로 전달된 액션에 들어갑니다. 세부 정보
Region은 명시적인 `details_label`을 사용하고, Tab 스톱을 추가하지 않으며, 전체 텍스트로 이름
붙은 Paragraph 하나를 담습니다. 고정된 GPUI API는 네이티브 트리거/콘텐츠 관계 ID를 노출하지
않습니다. 닫힌 세부 정보는 레이아웃, 액션 포커스 스톱, 접근성 노드를 추가하지 않습니다.

포인터, Enter, Space는 기존 트리거를 통해 전환합니다. 세부 정보 안의 액션이 포커스를 가진
상태에서 닫으면 포커스는 살아 있는 트리거로 돌아갑니다. 트리거가 비활성화되어 있으면 기존
Collapsible 수명 주기는 대신 Tab이 아닌 루트를 사용해 펼침 영역 밖으로 이동할 수 있게 합니다.
트리거를 비활성화해도 열린 세부 정보나 전달된 액션은 닫히거나 비활성화되지 않으며, 그 활성화
상태는 애플리케이션과 기존 Button에 속합니다. 요약이나 세부 정보 문자열을 바꿔도 유지되는 열림
상태나 포커스는 초기화되지 않습니다. 호스트 전체나 포커스된 액션을 제거하기 전에
애플리케이션은 유지되는 대상으로 포커스를 옮겨야 합니다.

프레임에는 제한된 너비를 주세요. 요약과 본문은 GPUI 텍스트 레이아웃으로 줄바꿈되며 잘리지
않고 세로로 늘어납니다. 선택적인 `.action(...)` 요소는 세부 정보 안에서 본문 뒤에 놓이며,
컨테이너를 사용하면 자체 레이아웃으로 여러 컨트롤을 제공할 수 있습니다. `Styled`는 바깥
프레임을 사용자 정의하고, 전달된 팔레트는 트리거와 Paragraph의 스타일을 지정합니다. 긴 세부
정보는 부모의 기존 ScrollArea를 사용하며, 내부 뷰포트나 새로운 스크롤 키 처리는 없습니다.

두 모양 모두 Help의 State ownership 패널에서 설정 미리 보기 뒤에 Trace를 둡니다. 요약은 현재
세션 이름을 사용하고, 세부 정보는 현재 세션, Calendar 선택, 프리셋, 그리기 도구, 커서와 툴바
설정, 메모 값을 읽습니다. Close details는 기존 `CollapsibleState::set_open(false, ...)`를
호출하며, 이는 요약으로 포커스를 복원합니다. 기반 폼을 편집하면 보이는 텍스트가 갱신되고,
설정을 닫았다가 다시 열어도 유지되는 펼침 상태와 폼 값이 보존됩니다.
이 소비자 코드는 현재 설정을 설명할 뿐이며 작업, 잡, 모델 추론을 기록하지 않습니다. Trace에는
로그 소스, 파서, 스트리밍 출력, 전송, 타임라인 모델이 없습니다. Item은 정적인 범용 행으로
남고, Message는 작성된 콘텐츠를 표시하며, 공용 펼침 동작은 계속 Collapsible이 소유합니다.
