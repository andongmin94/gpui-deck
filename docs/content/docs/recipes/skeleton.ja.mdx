[`skeleton.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/skeleton.rs) は、静的で装飾的な
プレースホルダーです。アプリケーションが寸法を渡し、準備できたコンテンツに
置き換えるタイミングを決めます。

```rust
Skeleton::new("preview-placeholder", palette)
    .w(px(180.))
    .h(px(16.))
    .rounded(px(4.))
```

デフォルトは、コンシューマーのフォントサイズと同じ高さの全幅の線で、その
罫線の色、角丸、不透明度 0.35 を使用します。通常の `Styled` による調整で、
テキストの行、ブロック、円形のプレースホルダーを作れます。このサーフェスはタイマーや
アニメーションを所有しないため、どのモーションの設定でも静止したままです。

Skeleton は、ネイティブのロール、アクセシブルな名前、子要素、フォーカスストップを追加しません。
サンプルが Spinner でそうしているように、読み込み中の操作には別途名前を付けてください。
読み込み状態やコンテンツの計測は所有せず、プレースホルダーの集まりは通常の
アプリケーションのレイアウトです。サンプルでは、パーセンテージの塗りがまだ
利用できない場所に 1 つ表示し、既知の進捗が戻ったときに取り除きます。
