[`code_block.rs`](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/recipes/code_block.rs)는 기존 Button,
GPUI 클립보드, ScrollArea로 읽기 전용 여러 줄 코드를 조합합니다.

```rust
CodeBlock::new(
    "session-configuration",
    configuration_json,
    "Session configuration",
    &configuration_scroll,
    &configuration_focus,
    palette,
);
```

`ScrollHandle`과 `FocusHandle`은 애플리케이션에 유지하세요. 전달된 레이블은 Copy 버튼
옆에 표시되며, 이 버튼의 접근 가능한 이름은 `Copy {label}`입니다. 코드는 네이티브 Code
시맨틱과 원본 전체 텍스트를 접근 가능한 이름으로 노출합니다. 뷰포트는 키보드 포커스
대상입니다. Copy는 기존 포인터, Enter, Space, 포커스 동작을 갖는 일반 Button으로
남습니다. 레시피는 텍스트 입력 노드, 편집기 상태, 선택 모델을 추가하지 않습니다.

기본 프레임은 높이 12 rem이며 사용 가능한 너비를 채웁니다. 헤더는 크기가 제한된 코드
뷰포트 밖에 놓입니다. `Styled`로 프레임을 사용자 정의하되, ScrollArea가 긴 본문과 줄을
담을 수 있도록 높이와 너비를 제한된 상태로 유지하세요. 코드는 팔레트의 코드 글꼴과 전경색을
사용합니다. 네이티브 GPUI 텍스트 레이아웃은 전달된 줄을 소프트 줄바꿈 없이 표시하며,
가로와 세로 넘침은 같은 ScrollArea 안에 머뭅니다. 레시피는 코드를 파싱하지 않으며 구문
강조, 줄 번호, 가상화 렌더링을 추가하지 않습니다.

Copy는 화면 밖 콘텐츠와 빈 문자열을 포함해 전달된 문자열 전체를 `App::write_to_clipboard`로
보냅니다. 공백, 줄 끝, 마지막 줄바꿈을 잘라내거나 정규화하거나 바꾸지 않습니다. LF, CRLF,
유니코드 콘텐츠는 복사된 내용에 그대로 보존됩니다. 화면에 보이는 텍스트는 GPUI가 셰이핑하며,
레시피는 별도의 탭 간격 정책이나 시각적 CRLF 정규화를 정의하지 않습니다. 복사됨 상태를
위한 별도 타이머나 자동 알림은 없습니다.

코드 뷰포트 자체에 포커스가 있으면 수정 키 없는 화살표 키는 각 축으로 스크롤하고, Page
Up/Down은 세로로 스크롤하며, Home은 왼쪽 위로, End는 오른쪽 아래로 이동합니다. 오프셋은
콘텐츠의 스크롤 범위 안에 머뭅니다. Tab과 Shift-Tab은 일반 이동을 유지하고, Escape는
바깥 모달이 계속 사용할 수 있으며, 수정 키가 있는 입력은 애플리케이션에 맡깁니다.
Copy 버튼의 키 이벤트는 Button의 계약을 따릅니다. 코드 위의 휠 제스처는 가장자리에서도 그
뷰포트 안에 머뭅니다. 부모 Sheet를 움직이려면 뷰포트 밖에서 스크롤하세요.

두 모양 모두 Help의 State ownership 패널에서 소스 경로 식별자 앞에 CodeBlock을 사용합니다.
소비자 코드는 기존 `serde_json` 의존성으로 현재 유지되는 설정을 JSON으로 직렬화합니다.
이는 표시와 복사를 위한 스냅샷이며, 복사해도 설정을 파싱하거나 적용하지 않습니다. 예제는
소비자 빌더를 메인 렌더 함수와 분리하고, 기존 Sheet, 포커스 가두기, 부모 스크롤을
재사용합니다. Typography는 계속해서 산문과 짧은 인라인 코드를 다루고, CodeBlock은 크기가
제한된 여러 줄 화면 표현을 소유합니다.
