[`item.rs`](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/recipes/item.rs) は、タイトル、任意の
説明、先頭のメディア、全幅のヘッダーとフッター、任意の
末尾のアクションをまとめます。

```rust
Item::new("recording-preset-item", "Recording preset", palette)
    .description(selected_preset_label)
    .media(record_dot)
    .header("Applies to new recordings")
    .footer(recording_date)
    .action(preset_preview_and_edit)
```

そのネイティブな Group は、タイトルで名前付けされ、説明で説明されます。
テキストの列は縮小できる一方、メディアとアクションは必要な幅を保ちます。
ヘッダーとフッターは、その行の上と下でフレームの全幅にわたります。サンプルでは、
装飾的な描画の録画ドット、控えめなスコープのヘッダー、フッターとして選択された録画日、
そして既存の HoverCard のトリガーを渡しています。このトリガーは、ホバー/フォーカスでプリセットをプレビューし、
通常の起動で設定を開きます。そのフォーカスハンドル、ボタンの
名前、フォーカスの復帰の動作は維持されます。

スロットは、ロール、名前、フォーカスストップを追加せず、自身のコンテンツの
セマンティクスだけを持ちます。Avatar のような情報を伝えるメディアには独自の名前を付け、
装飾的な形状には名前を付けないでください。インストール済みのフォントに依存する記号グリフより、描画した形状を優先してください。この行には、行全体のクリック、Tab ストップ、選択
値、リストのナビゲーションはありません。渡されたコントロールが、自身のセマンティクスとアクションを持ちます。関連する
入力のラベルとバリデーションには、Field を使用してください。別個の ItemGroup は、
現在のレシピのスコープの外です。`Styled` でフレームと余白を変更できます。
