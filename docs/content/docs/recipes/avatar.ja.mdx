[`avatar.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/avatar.rs) は、明示的な代替テキストと
アプリケーションが渡すフォールバックテキストを持つ、円形の画像を表示します。

```rust
Avatar::new("preset-avatar", "Balanced preset artwork", "BL", palette)
    .image(preset_artwork)
    .size(rems(2.5))
```

`image` は GPUI の既存の `ImageSource` への変換を受け付けます。省略すると
フォールバックがすぐに表示され、画像のエラーでもフォールバックが表示されます。画像が
保留中の間は、フォールバックを表示する前に GPUI ネイティブの 200 ms の読み込み遅延が適用されます。
デコード、読み込み、キャッシュ、再描画は GPUI が担います。レシピは、別個の
読み込みタスク、タイマー、キャッシュ、再試行ポリシーを追加しません。

ルートは、どの状態でも、ネイティブな Image ロールと指定されたアクセシブルな名前を 1 つ提供します。
画像とフォールバックは、個別の名前やフォーカスストップを追加しません。表示されるイニシャルに頼らず、
画像の意味を説明する名前を渡してください。
フォールバックテキストとそのローカライズはアプリケーションが選びます。このレシピは
名前からイニシャルを導出しません。デフォルトのフレームは 2.5 rem 四方で、パレットの
色と円形のクリップが適用されます。`Styled` でサイズと色を変更できます。円にするには幅と
高さを等しく保ってください。画像には GPUI の cover フィットが使われます。ステータスバッジや
インタラクティブなアクションは、アプリケーションでの構成のままです。

このサンプルは、Balanced プリセット用に [`preset-avatar.svg`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/assets/preset-avatar.svg)
を埋め込んでいます。他のプリセットは `PR` や `HQ` のような明示的なテキストを使用し、
未選択の場合は `?` を使用します。アクセシブルな名前は、現在のプリセットのラベルから導出されます。
ソースは、保持されている Combobox の状態から既存の HoverCard を描画する際に選ばれ、
2 つ目の選択済みプリセットの値はありません。この
同梱のアートワークは、ネットワークリクエストを必要としません。レシピをコピーするときは、
アプリケーションが自身のアセットを用意してください。


`AvatarGroup::new(id, "Team members", palette)` は、shadcn の avatar group のように
`.avatar(...)` のアイテムを重ねます。表示される各アバターはサーフェスと同じ色のリングの中にあり、
前のアバターと重なります。`.max_visible(n)` は最初の `n` 個を表示し、
隠れた人々を Label の名前で列挙する「+N」のチップを追加するため ("2 more: Cy Lee, Di Cho")、
支援技術から誰も失われません。フレームは、フォーカスストップのない名前付きの Group です。
プリセットのプレビューでは、5 人のうち 3 人を表示しています。
