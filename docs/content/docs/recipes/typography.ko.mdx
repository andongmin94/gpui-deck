[`typography.rs`](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/recipes/typography.rs)는 `Heading`,
`Paragraph`, `InlineCode`를 하나의 화면 표현 레시피로 제공합니다. 텍스트 셰이핑, 레이아웃,
그리기는 GPUI가 소유합니다. 콘텐츠, 개요 수준, 글꼴 선택, 사용 가능한 너비, 주변 간격은
애플리케이션이 전달합니다.

```rust
Heading::new("help-title", "Help", 2, palette);

Paragraph::new("state-ownership", palette)
    .text("The application retains ")
    .code("DialogState")
    .text(" and ")
    .code("InputState")
    .text(" while panels are closed.");

InlineCode::new(
    "help-source",
    "crates/base/examples/two_styles.rs",
    palette,
);
```

`Heading::new`에는 양수인 네이티브 제목 수준이 필요합니다. 보이는 텍스트가 전체 접근 가능한
이름도 제공합니다. 수준은 콘텐츠 개요에 따라 선택하세요. 수준을 바꾸면 기본 시각적 크기와
별개로 시맨틱 계층이 바뀝니다. 모든 수준은 `1.25 * palette.font_size`와 semibold 굵기에서
시작합니다. 다른 시각적 크기, 색상, 간격에는 일반 `Styled` 세부 조정을 사용하세요.

`Paragraph::text`와 `Paragraph::code`는 전달된 텍스트를 순서대로 덧붙이며, 공백을 넣거나
마크업을 해석하지 않습니다. 구두점과 공백은 텍스트 조각에 포함하세요. 네이티브 `StyledText`
하나가 문단 전체를 셰이핑하므로 인라인 코드는 같은 텍스트 흐름과 줄바꿈에 속합니다. 문단의
기본값은 일반 줄바꿈, 팔레트의 본문 크기와 전경색, 글꼴 크기의 1.5배 줄 높이입니다. 긴
텍스트에는 부모에 사용 가능한 너비를 주고 높이는 자동으로 두세요. 레시피는 잘라내기, 고정
높이, 독립적인 스크롤을 추가하지 않으며, 넘침은 주변 Sheet/ScrollArea 콘텐츠가 소유합니다.

문단은 네이티브 Paragraph 시맨틱과 이어 붙인 전체 텍스트를 하나의 접근 가능한 이름으로
노출합니다. 코드 범위는 소비자의 코드 글꼴과 배경을 네이티브 텍스트 런 스타일로 사용합니다.
GPUI는 스타일이 적용된 범위마다 접근성 역할을 노출하지 않으므로, 이 범위들은 별도의 Code
노드를 만들지 않습니다. 코드에 자체 요소가 필요하면 `InlineCode`가 별도로 이름 붙은 네이티브
Code 요소를 제공합니다. 코드가 산문 문장 안에 들어갈 때는 `Paragraph::code`를 사용하세요.
세 타입 모두 정적 텍스트이며 포커스 스톱이나 키보드 액션을 추가하지 않습니다.

소비자의 `palette.code_font_family`가 요청할 코드 글꼴을 선택합니다. 예제는 Linux에서 DejaVu
Sans Mono, Windows에서 Consolas, macOS에서 Menlo를 요청합니다. 애플리케이션은 자신의 환경에
맞는 글꼴을 제공해야 합니다. `Styled`가 각 요소의 레이아웃과 텍스트 표현을 제어합니다.
Paragraph의 코드 범위는 본문 텍스트 안에서 명시적인 코드 글꼴과 배경 스타일을 유지합니다.
보이는 크기를 바꿔도 Heading의 네이티브 수준이나 접근 가능한 이름에 쓰이는 텍스트는 바뀌지
않습니다.

두 모양 모두 Help 탭에서 이 레시피를 사용합니다. 수준 2 Help 제목이 기존 수준 3 Accordion
제목 위에 놓이고, 패널에는 유지되는 애플리케이션 상태에 관한 산문과 독립적으로 이름 붙은 소스
식별자가 들어갑니다. 키보드 도움말 팝업에는 기존 Breadcrumb 액션과 Kbd 힌트를 유지하면서
간결한 제목이 추가됩니다. 더 긴 설명은 Sheet의 스크롤되는 본문 안에 남습니다. 디버그 렌더링
중 스택 사용량을 줄이기 위해 소비자 빌더는 작은 도우미 함수로 나뉘어 있습니다.

이 레시피는 텍스트 화면 표현과 메타데이터를 제공합니다. Markdown 파싱, 구문 강조, 코드 복사,
텍스트 편집, 여러 줄 Code Block 조합은 범위 밖입니다. 유지되는 상태나 두 번째 텍스트 렌더러를
도입하지 않습니다.
