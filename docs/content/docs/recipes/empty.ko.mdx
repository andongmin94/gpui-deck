[`empty.rs`](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/recipes/empty.rs)는 GPUI의 `Empty`
요소와 혼동하지 않도록 `EmptyState`를 내보냅니다. 이름 있는 그룹, 수준 2 제목, 설명,
선택적인 미디어/액션 슬롯을 제공합니다.

```rust
EmptyState::new("empty-results", "No results", "Try another search.", palette)
    .media(Badge::new("result-count", "0 results", palette))
    .action(clear_search_button)
```

레시피는 검색, 로딩, 알림, 포커스 상태를 소유하지 않습니다. 전달된 미디어가 정보를 전달할
때는 그 미디어가 자신의 접근 가능한 설명을 소유합니다. 예제는 이 레시피를 `Command` 안의
`CommandList` 옆에 두므로, 액션은 listbox 밖의 일반 Button입니다. Clear search는
`CommandState::set_query`를 호출하고 기존 쿼리 입력으로 포커스를 돌려보냅니다. 대화상자는
열린 채로 유지되며 어떤 명령도 실행되지 않습니다. `Styled`로 바깥 프레임을 재정의할 수
있습니다.
