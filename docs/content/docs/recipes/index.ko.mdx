---
title: 전체 레시피
description: "라이브러리 위에 구축된 복사 가능한 화면 표현 소스입니다. 로컬 CLI로 설치하고 자유롭게 수정해 사용하세요."
---

<Cards>
  <Card title="Alert" href="/ko/docs/recipes/alert/">
    인라인 제목과 설명을 표시하며, destructive 스타일과 긴급성을 각각 명시적으로 지정합니다.
  </Card>
  <Card title="Aspect Ratio" href="/ko/docs/recipes/aspect-ratio/">
    유한한 양수 너비/높이 비율과 애플리케이션이 소유하는 콘텐츠를 담는, 잘라내기가 적용된 미디어 프레임입니다.
  </Card>
  <Card title="Attachment" href="/ko/docs/recipes/attachment/">
    파일 이름, 전달받은 미디어 유형과 크기, 선택적인 기존 액션을 담는 이름 있는 파일 메타데이터 그룹입니다.
  </Card>
  <Card title="Avatar" href="/ko/docs/recipes/avatar/">
    GPUI의 이미지 로더와 캐시를 사용하며 명시적인 대체 텍스트를 갖는 이름 있는 원형 이미지입니다. 이름 있는 "+N" 오버플로를 갖는 겹침형 AvatarGroup도 포함합니다.
  </Card>
  <Card title="Badge" href="/ko/docs/recipes/badge/">
    secondary와 accent 모양을 갖는 정적 레이블입니다.
  </Card>
  <Card title="Bubble" href="/ko/docs/recipes/bubble/">
    수신/발신 표면, 묶인 작성자/시간 레이블, 전달받은 반응을 제공합니다.
  </Card>
  <Card title="Button Group" href="/ko/docs/recipes/button-group/">
    선택적인 텍스트 슬롯을 갖는, 가로/세로로 연결된 버튼입니다.
  </Card>
  <Card title="Card" href="/ko/docs/recipes/card/">
    제목, 설명, 헤더 액션, 본문, 푸터를 갖는 이름 있는 영역입니다.
  </Card>
  <Card title="Code Block" href="/ko/docs/recipes/code-block/">
    읽기 전용 여러 줄 코드, 전체 텍스트를 그대로 복사하는 Copy 액션, 키보드로 조작할 수 있는 제한된 양축 스크롤을 제공합니다.
  </Card>
  <Card title="Data Table" href="/ko/docs/recipes/data-table/">
    텍스트 필터링/정렬, 페이지 나누기, 페이지/행 체크박스 선택, 열 표시 여부, 안정적인 ID 기반 행 액션을 제공합니다.
  </Card>
  <Card title="Empty" href="/ko/docs/recipes/empty/">
    제목, 설명, 선택적인 미디어와 전달받은 액션을 갖는 이름 있는 정적 그룹입니다.
  </Card>
  <Card title="Input Group" href="/ko/docs/recipes/input-group/">
    기존 입력을 감싸는 공용 프레임으로, 앞/뒤 애드온과 가로/세로 레이아웃을 지원합니다.
  </Card>
  <Card title="Item" href="/ko/docs/recipes/item/">
    제목, 설명, 선택적인 미디어, 헤더, 푸터, 뒤쪽 액션을 갖는 이름 있는 콘텐츠 행입니다.
  </Card>
  <Card title="Kbd" href="/ko/docs/recipes/kbd/">
    이름 있는 정적 키캡과 +로 연결된 키 조합입니다.
  </Card>
  <Card title="Marker" href="/ko/docs/recipes/marker/">
    장식용 구분선 사이에 놓인 이름 있는 날짜/상태 레이블 하나로, 텍스트가 줄바꿈되며 포커스 스톱이 없습니다.
  </Card>
  <Card title="Message" href="/ko/docs/recipes/message/">
    작성자/시간 메타데이터, 줄바꿈되는 문단, 선택적인 기존 액션을 갖는 읽기 전용 댓글입니다.
  </Card>
  <Card title="Pagination" href="/ko/docs/recipes/pagination/">
    제어되는 이전/다음 버튼, 현재 페이지 텍스트, 빈 페이지/첫 페이지/마지막 페이지 경계를 제공합니다.
  </Card>
  <Card title="Sheet" href="/ko/docs/recipes/sheet/">
    Dialog 위에 네 가장자리 중 하나로 표시되는 모달 화면 표현으로, 뷰포트로 제한된 크기, 고정된 헤더/푸터, 스크롤되는 본문 하나를 갖습니다.
  </Card>
  <Card title="Sidebar" href="/ko/docs/recipes/sidebar/">
    이름 있는 그룹형 내비게이션, 일반 Button, 현재 페이지 메타데이터, 선택적인 전체/그룹 Collapsible 상태, 선택적인 아이콘 레일을 제공합니다.
  </Card>
  <Card title="Skeleton" href="/ko/docs/recipes/skeleton/">
    애플리케이션이 크기와 모양을 제어하는 정적 장식용 자리 표시자입니다.
  </Card>
  <Card title="Spinner" href="/ko/docs/recipes/spinner/">
    GPUI의 동작 줄이기 설정을 따르는 회전 호를 갖는, 이름 있는 불확정 Progress입니다.
  </Card>
  <Card title="Trace" href="/ko/docs/recipes/trace/">
    기존 Collapsible 수명 주기 위에 구축된, 펼칠 수 있는 요약과 이름 있는 읽기 전용 세부 정보이며 선택적인 액션을 갖습니다.
  </Card>
  <Card title="Typography" href="/ko/docs/recipes/typography/">
    명시적인 수준을 갖는 이름 있는 제목, 네이티브 인라인 코드 텍스트 런을 갖는 문단, 독립적으로 이름 붙은 코드 요소를 제공합니다.
  </Card>
</Cards>
