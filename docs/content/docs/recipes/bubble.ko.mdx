description: "수신/발신 표면, 묶인 작성자/시간 레이블, 전달받은 반응을 제공합니다."
---

카탈로그는 `crates/base/examples/recipes` 아래에 소스를 소유하는 독립된 화면 표현 두 개를
추가합니다. `bubble.rs`는 Bubble 카탈로그 항목으로, 수신/발신 정렬, 묶인 작성자/시간
메타데이터, 줄바꿈되는 메시지 본문, 전달받은 반응 액션을 제공합니다. 활성화와 포커스는
기존 Button이 소유하며, 메시지 묶음과 반응 값은 대화 뷰에 속합니다. 전송, 영속화, 별도의
메시지 상태 엔진은 추가하지 않습니다.

`chart.rs`는 공개 Chart 계열의 화면 표현이며, 두 번째 카탈로그 항목으로 세지 않습니다.
네이티브 캔버스 선/막대/영역, 누적, 파이/도넛, 레이더 경로, 축 또는 방사형 레이블,
계열 Toggle, 검사 중인 값 표시, 같은 데이터의 Table을 제공합니다. 색상 배열, 레이아웃,
서식은 애플리케이션이 소유합니다. 공용 Chart 계약은
[레이아웃과 데이터 가이드](../guides/layout-data.mdx)를 참고하세요.

`cargo run -p gpui-design --example catalogue --locked`를 실행하면 이 두 화면 표현을 각각
MessageScroller/Questionnaire, Carousel/Direction과 함께 사용할 수 있습니다. 기존
`two_styles` 예제는 계속해서 세션 중심 레시피를 담습니다.
