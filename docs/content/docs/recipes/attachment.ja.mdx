---
title: Attachment
description: "ファイル名、渡されたメディアタイプとサイズ、任意の既存アクションを持つ、名前付きのファイルメタデータのグループ。"
---

[`attachment.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/attachment.rs) は、ファイルの
名前、メディアタイプ、サイズを、アプリケーションが渡すテキストとして表示し、任意の既存の
アクションを付けられます。メタデータを説明するもので、コンテンツ自体はアプリケーションが担います。

```rust
Attachment::new(
    "configuration-attachment",
    "session-configuration.json",
    "application/json",
    format!("{} bytes (UTF-8)", configuration.len()),
    palette,
)
.action(inspect_json_button)
```

ネイティブな Group のアクセシブルな名前は、完全なファイル名です。その説明は、
ファイル名の下に表示される `media_type · size_label` のテキストと同じです。可視のファイル名と
メタデータの子要素には、個別のネイティブなロールや名前がないため、各値は
グループを通じて 1 回だけ公開されます。渡されたアクションの Button は、自身の
名前とロールを保持します。Attachment のフレームは、Tab ストップ、行全体のクリック、
選択状態、リンク先、ライブアナウンスを追加しません。

3 つのメタデータの値はすべて、渡された文字列です。単位、
ローカライズ、利用できないメタデータの表現方法はアプリケーションが選びます。レシピは、ファイル名の解析、
種類の推測、ファイルの検査、バイト数の書式設定、主張されたサイズの検証を行いません。
0 バイトはそのまま表示できます。メタデータだけでは、ドキュメントビューアーやファイルへのリンクを
提供することにはならないため、通常の Group を使用しています。
Item の汎用的なタイトル/説明の行とは違い、Attachment には明示的なファイル
メタデータがあります。Message の作成者付きの Comment と本文とは違い、作成者や配信を主張することなく、
別個のコンテンツリソースを特定します。

フレームは、範囲が制限された親いっぱいに広がります。ファイル名とメタデータは切り詰めずに折り返され、
フレームは縦方向に伸びます。アクションはテキストの下に置かれるため、ファイル名の幅と
競合しません。`Styled` は、フレームと継承されるテキストのプレゼンテーションをカスタマイズします。長い
コレクションは、アプリケーションの既存の ScrollArea に置いてください。`.action(...)` は 1 つの要素を受け取り、
既存の Button や、利用可能な幅に収まるコントロールを持つ
アプリケーション所有のコンテナーを渡せます。Button は引き続き、有効状態、ポインター/Enter/Space による起動、フォーカス、
Tab/Shift+Tab による移動を担います。フォーカス中のアクションを削除する場合のフォーカスポリシーは
アプリケーションが担います。Attachment に新しいフォーカスコントローラーはありません。

どちらの外観でも、Attachment は Help の State ownership パネルで、既存の
CodeBlock の上に使われています。コンシューマーは現在の設定を一度だけシリアライズし、
コードとメタデータに同じ文字列を使い、`session-configuration.json`、
`application/json`、およびその UTF-8 のバイト数を表示します。名前やメモを編集すると、
表示される JSON とともにそのメタデータが変わります。Inspect JSON は既存のコードのビューポートにフォーカスし、
その既存のスクロールとキーボードの動作を使用します。説明のテキストは、
このコンテンツがメモリ内にあり、保存されていないことを示しています。ファイルは作成も開きもされず、
アップロードもダウンロードも行われません。既存の CodeBlock の Copy アクションは
独立したままです。Attachment は、クリップボード操作、プレビューレンダラー、進捗
状態、トランスポート、ストレージの仕組みを追加しません。
