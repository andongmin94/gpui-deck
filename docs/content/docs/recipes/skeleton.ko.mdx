[`skeleton.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/skeleton.rs)는 정적 장식용
자리 표시자입니다. 치수는 애플리케이션이 전달하며, 준비된 콘텐츠로 언제 교체할지도
애플리케이션이 결정합니다.

```rust
Skeleton::new("preview-placeholder", palette)
    .w(px(180.))
    .h(px(16.))
    .rounded(px(4.))
```

기본값은 소비자의 글꼴 크기만큼 높은 전체 너비 줄이며, 소비자의 테두리 색상, 모서리 반경,
0.35 불투명도를 사용합니다. 일반 `Styled` 세부 조정으로 텍스트 줄, 블록, 원형 자리 표시자를
만들 수 있습니다. 표면은 타이머나 애니메이션을 소유하지 않으므로 어떤 동작 설정에서도 정지
상태로 남습니다.

Skeleton은 네이티브 역할, 접근 가능한 이름, 자식, 포커스 스톱을 추가하지 않습니다. 예제가
Spinner로 하듯이 로딩 작업에는 별도로 이름을 주세요. 로딩 상태나 콘텐츠 측정을 소유하지
않으며, 여러 자리 표시자를 모은 것은 일반 애플리케이션 레이아웃입니다. 예제는 퍼센트 채우기를
아직 사용할 수 없을 때 하나를 표시하고, 알려진 진행률이 복원되면 제거합니다.
