---

[`pagination.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/pagination.rs)는 일반
Button을 이름 있는 네이티브 내비게이션으로 조합합니다. 0부터 시작하는 페이지 인덱스, 페이지
수, 콜백은 애플리케이션이 전달합니다.

```rust
Pagination::new("preset-pages", "Recording preset pages", page, page_count, palette)
    .on_change(move |page, _, cx| {
        table_state.update(cx, |state, cx| state.set_page(page, cx));
    })
```

비어 있지 않은 컬렉션에서는 페이지 인덱스가 페이지 수보다 작아야 합니다. 빈 결과는 인덱스
0과 페이지 수 0을 사용하고, `No pages`를 표시하며, Previous와 Next를 모두 비활성화합니다.
그 밖의 경우 Previous 뒤에 번호 버튼이 옵니다. 최대 일곱 페이지까지는 그대로 표시하고, 더 긴
컬렉션은 첫 페이지와 마지막 페이지, 현재 페이지와 그 이웃을 유지하며, 생략된 각 구간은 정적
`More pages` 레이블로 표시합니다. 페이지를 넘겨도 항목 수가 일곱으로 유지되므로 컨트롤이
움직이지 않습니다. 현재 페이지는 네이티브 현재 페이지 메타데이터와 선택 스타일을 가지며
변경을 요청하지 않습니다. Previous는 첫 페이지에서, Next는 마지막 페이지에서
비활성화됩니다. 버튼은 액션 이후 비활성화되는 버튼에 포커스가 남는 경우를 포함해 일반 Tab과
활성화 동작을 유지합니다. 레시피는 유지되는 페이지나 데이터를 소유하지 않으며, 라우팅과
데이터 가져오기는 애플리케이션에 속합니다.
