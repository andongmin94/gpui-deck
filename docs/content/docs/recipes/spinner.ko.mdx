---

[`spinner.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/spinner.rs)는 기존 불확정
Progress에 회전하는 호를 추가합니다. 작업의 접근 가능한 이름을 전달하세요.

```rust
Spinner::new("preview-progress", "Preview progress", palette)
    .size(rems(1.25))
    .text_color(palette.accent)
```

기본 크기는 1 rem이고 기본 색상은 소비자의 accent입니다. `Styled`가 루트를 제어하며, 호는
루트의 실제 경계와 텍스트 색상을 따릅니다. Progress가 유일한 네이티브 ProgressIndicator
역할, 레이블, 숫자 범위를 제공하며 현재 숫자 값은 없습니다. 시각적인 호는 별도의 역할, 접근
가능한 이름, Tab 스톱을 추가하지 않습니다. 이는 불확정 진행 표시기이며 자동 라이브 알림을
제공하지 않습니다.

1초 간격으로 반복되는 애니메이션은 GPUI의 `AnimationExt`가 소유합니다.
`App::reduce_motion()`이 활성화되면 애니메이션 프레임을 요청하지 않고 정적인 호를
렌더링합니다. 애플리케이션은 `App::set_reduce_motion(bool)`로 이 기존 설정을 지정할 수
있으며, 운영체제 설정과의 자동 동기화는 이 레시피의 범위 밖입니다. 레시피 전용 애니메이션
컨트롤러, 유지되는 로딩 상태, 타이머는 없습니다.

애플리케이션이 작업을 대기 중으로 보는 동안 Spinner를 마운트하고, 작업이 끝나면 제거하세요.
예제에서는 기존 Unknown progress 토글이 같은 크기 제한 행에서 확정 막대를 Spinner와
Skeleton으로 바꿉니다. 두 진행 화면 표현은 모두 `preview-progress` ID와 접근 가능한 이름을
유지합니다. 알 수 없는 상태가 표시되는 동안 Slider는 알려진 값을 유지하며, Reset preview는
40%의 알려진 진행률로 돌아갑니다. 이는 여전히 제어되는 미리 보기이며, 레시피는 녹화나
백그라운드 작업을 시작하지 않습니다.
