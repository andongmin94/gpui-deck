[`trace.rs`](https://github.com/andongmin94/gpui-design/blob/main/crates/base/examples/recipes/trace.rs) は、名前付きの読み取り専用の詳細と、任意の
アプリケーションのアクションに展開される要約を表示します。既存の
Collapsible の部品、Button の動作、Typography の Paragraph を合成します。

```rust
let disclosure = cx.new(CollapsibleState::new);
// Retain this entity and observe it so the application view redraws.

Trace::new(
    "settings-trace",
    &disclosure,
    "Current settings · MiniCast",
    "Current settings details",
    detail_text,
    palette,
)
.action(close_details_button)
```

アプリケーションは、渡した `Entity<CollapsibleState>` を所有し、監視します。
その初期状態は `default_open` で設定し、後の変更には既存の `set_open` と
`set_disabled` メソッドを使用します。閉じている間も、ルートとトリガーはマウントしたままにしてください。Trace は、追加の開閉状態、
イベント型、データ収集、実行コントローラーを提供しません。

既存の Collapsible のルートは、Tab 対象外のフォーカススコープを持つ、名前のないネイティブな Group です。
そのトリガーは、完全な要約で名前付けされた Button で、CollapsibleTrigger が提供するネイティブな
展開と無効のメタデータを持ちます。可視の展開の手がかりは、ロールも名前も追加しません。トリガーから
開いても、フォーカスはそこに残り、通常の Tab による移動で、渡されたアクションに入ります。詳細の Region は、
明示的な `details_label` を使用し、Tab ストップを持たず、全文で名前付けされた
Paragraph を 1 つ含みます。固定された GPUI API は、ネイティブな
トリガーとコンテンツの関連 ID を公開しません。閉じた詳細は、レイアウト、アクションの
フォーカスストップ、アクセシビリティノードに寄与しません。

ポインター、Enter、Space は、既存のトリガーを通じて切り替えます。詳細内のアクションが
フォーカスを持っているときに閉じると、フォーカスは現存するトリガーに戻ります。トリガーが
無効な場合は、既存の Collapsible のライフサイクルが代わりに Tab 対象外の
ルートを使用するため、移動で開閉部分から離れられます。トリガーを無効にしても、開いている詳細や、
渡されたアクションが閉じたり無効になったりすることはありません。それらの有効状態は
アプリケーションとその既存の Button に属します。要約や詳細の文字列を変更しても、保持されている
開閉状態やフォーカスはリセットされません。アプリケーションは、ホスト全体やフォーカス中のアクションを削除する前に、
保持されているフォーカス対象へ移動する必要があります。

フレームには上限のある幅を与えてください。要約と本文は GPUI のテキストレイアウトに従って折り返され、
切り詰められることなく縦方向に伸びます。任意の `.action(...)` 要素は、
本文の後ろの詳細内に置かれ、コンテナーを使えば、それ自身の収まるレイアウトで複数のコントロールを渡せます。`Styled` は外側のフレームをカスタマイズし、
渡されたパレットがトリガーと Paragraph のスタイルを決めます。長い詳細は、親の既存の
ScrollArea を使用し、内側のビューポートや新しいスクロールキーの処理はありません。

どちらの外観でも、Trace は Help の State ownership パネルの、設定プレビューの後に置かれます。
要約には現在のセッション名を使い、詳細は、現在のセッション、Calendar の選択、プリセット、描画ツール、カーソルとツールバーの
設定、メモの値を読み取ります。Close details は、既存の
`CollapsibleState::set_open(false, ...)` を呼び出し、要約へのフォーカスを復元します。
元のフォームを編集すると、表示されるテキストが更新されます。設定を閉じて再び開いても、
保持されている開閉状態とフォームの値は維持されます。
このコンシューマーは現在の設定を説明するものであり、操作、ジョブ、
モデルの推論を記録しません。Trace には、ログのソース、パーサー、ストリーミング出力、トランスポート、
タイムラインモデルはありません。Item は引き続き静的で汎用的な行であり、Message は作成された
コンテンツを表示し、Collapsible は共有される開閉の動作を担い続けます。
