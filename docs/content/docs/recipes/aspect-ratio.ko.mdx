[`aspect_ratio.rs`](https://github.com/andongmin94/gpui-deck/blob/main/crates/base/examples/recipes/aspect_ratio.rs)는 GPUI의
기존 종횡비 레이아웃을 사용해 잘라내기가 적용된 미디어 프레임을 제공합니다.

```rust
AspectRatio::new("recording-frame", 16. / 9.)
    .w(px(320.))
    .rounded(palette.radius)
    .bg(palette.field)
    .child(media)
```

비율은 너비를 높이로 나눈 값이며 유한한 양수여야 합니다. 기본 너비는 부모를 채웁니다.
부모에 확정된 너비를 주거나 프레임에 `.w(...)`를 지정하세요. 높이는 자동으로 두어
GPUI가 너비에서 계산하도록 합니다. 명시적인 높이나 최소/최대 제약은 GPUI의 일반
레이아웃 규칙을 따르며, 선호 비율보다 우선할 수 있습니다.

자식은 프레임을 채우는 절대 위치 컨테이너 안에 놓이므로, 자식의 고유 크기가 프레임의
높이를 결정하지 않습니다. 크기를 넘는 콘텐츠는 잘리며, 프레임 밖의 포인터 상호작용도
마찬가지입니다. 컨테이너를 채워야 하는 이미지나 다른 자식에는 `.size_full()`을
지정하고, 이미지의 object fit은 해당 자식에서 선택하세요. 프레임은 접근성 역할, 이름,
포커스 스톱, 유지되는 상태를 추가하지 않습니다. 미디어 자식이 자신의 접근 가능한 설명과
상호작용을 제공합니다. 배경, 모서리 둥글기 등 화면 표현은 `Styled`를 통해 애플리케이션이
담당합니다.

프리셋 HoverCard는 현재 세션 이름을 담은 예시 녹화 프레임을 보여 줍니다. Presentation에는
4:3을, 다른 프리셋이나 선택이 비어 있을 때는 16:9를 사용합니다. 유지되는 프리셋을 바꾸면
다음 렌더링에서 비율이 바뀌고, 세션 이름을 편집하면 표시되는 텍스트가 바뀝니다. 전달된
자식은 형식을 설명하는 네이티브 Image 이름을 갖습니다. 미리 보기는 녹화를 만들지 않으며,
HoverCard의 비상호작용 콘텐츠에 컨트롤을 추가하지 않습니다.
