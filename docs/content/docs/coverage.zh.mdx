参考目录检查于 **2026-11-21**：
[shadcn/ui All Components](https://ui.shadcn.com/docs/components)。
其主目录包含 **66 个条目**，下文每个条目只列出一次。独立的
AI Elements 目录不在本次比较范围内；主目录中已有的对话类组件仍然包含在内。

GPUI Design 记录了 **42 个公开的库组件族和 23 个可复制的
呈现/组合配方**，提供 **65 个不同的实现**。
其余的目录条目 Native Select 被明确地**映射到 Select**
（针对 GPUI）。下文中的全部 **66 个参考条目都有已实现的范围或平台
映射**；没有任何条目处于未分配或 Pending 状态。

这是目录层面的覆盖，并非 shadcn/ui 功能的完整对等。每份约定
都有明确的限制，面向 HTML 的映射并不实现浏览器
控件或操作系统的选择器。这些数字不衡量性能、
无障碍合规性，也不代表原生桌面验证已经完成。

目标是达到可比的应用构建广度：共享的行为放在
库中，而可复用的呈现与界面组合，其源码归应用所有。
下面的分组描述的是我们自己的实现职责，
而不是 shadcn 的内部架构。`two_styles` 和 `catalogue` 原生示例
使用可复用的[呈现配方](./guides/recipes.mdx)。配方源码在
本仓库中分发；本地源码 CLI 会把配方、依赖、令牌和
许可证安装到使用方自有的模块中。不提供远程注册表。

## 状态含义

- **Available：**公开的组件族和使用方示例覆盖所述范围。
- **Recipe：**可复用的应用源码和可运行的使用方示例覆盖
  所述的呈现；该配方不在库的公开导出之内。
- **Mapped：**明确的 GPUI 平台等价物满足原生应用的
  需求；仅限浏览器的约定会被如实记录，而不是藏在别名背后。

## 完成标准与当前工作

目标是在原生 GPUI 上，在行为、无障碍、视觉
默认值和源码分发方面达到 shadcn/ui 级别的可用性。这 66 个条目的目录仅统计
范围覆盖。它不是完成百分比，也不是发布就绪的
声明。上文的 `Available`、`Recipe` 和 `Mapped` 并不意味着对等已经完成。

工作在此处和 Git 中跟踪，没有单独的进度报告。当一项能力的文档化使用方约定已实现、
在原生示例中演练过、由现有测试层中合适的一层覆盖，
并且文档准确时，它才算完成。平台观察与自动化检查分开记录。

| --- | --- | --- | --- |

## 参考对照

[shadcn 简介](https://ui.shadcn.com/docs)描述了源码所有权、
组合、分发和视觉默认值。可比的广度既包括
这些面向使用方的配方，也包括无头行为。

当前的 [Combobox](https://ui.shadcn.com/docs/components/base/combobox)
文档涵盖可编辑的自动补全和更多的选择变体；
这里的实现提供分组的单选/多选以及条目
替换。应用保留标签（chip）的呈现和异步请求的
所有权；这些能力是在深化同一个组件族，而不是新增组件。
[Command](https://ui.shadcn.com/docs/components/base/command) 包含对话框
组合，而不需要第二个独立的命令引擎。

[Date Picker](https://ui.shadcn.com/docs/components/base/date-picker) 由日历和弹出层部件
组合而成。
[Data Table](https://ui.shadcn.com/docs/components/base/data-table) 是在共享基础之上
构建特定应用表格的指南。
[Native Select](https://ui.shadcn.com/docs/components/base/native-select) 明确
封装了浏览器的 HTML 控件，因此其平台约定需要适配。
